## 실행 방법

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
uv sync
uv run python main.py
```

VS Code를 사용할 경우 `uv sync`로 생성된 `.venv`의 Python 인터프리터를 선택합니다.

## 자료구조 선택 근거

- `list`: 도서 객체와 대여 이력을 입력된 순서대로 유지하며 반복 조회하기 위해 사용합니다.
- `dict`: ISBN을 key로 도서의 상세 정보를 key-value 구조로 관리하기 위해 사용합니다.
- `set`: ISBN은 중복되면 안 되므로 고유값만 저장하고 중복 여부를 빠르게 확인하기 위해 사용합니다.
- `tuple`: 이미 발생한 대여/반납 이력 한 건을 이후에 변경하지 않도록 묶기 위해 사용합니다.

## 객체지향 설계

- `Book`: 도서명, 저자, ISBN, 대여 상태를 관리하는 부모 클래스입니다.
- `PrintedBook`: `Book`을 상속받고 페이지 수를 추가합니다.
- `Ebook`: `Book`을 상속받고 파일 형식을 추가합니다.
- 공통 데이터는 부모 클래스가 관리하고, 도서 유형별 상세 출력은 자식 클래스의 `show_info()`에서 오버라이딩합니다.
- 주요 데이터는 `__변수명` 형태의 프라이빗 변수로 관리하고 `property`를 통해 읽습니다.

## 예외 처리 및 디버깅 확인 내역

1. 메뉴에 문자를 입력하면 `int()` 변환에서 발생하는 `ValueError`를 처리하여 다시 입력받습니다.
2. 빈 문자열이나 공백만 입력하면 입력 단계에서 다시 요청합니다.
3. 이미 등록된 ISBN을 다시 입력하면 `set`을 이용해 중복을 차단합니다.
4. 존재하지 않는 ISBN으로 대여/반납을 시도하면 상태 변경 없이 안내합니다.
5. 이미 대여 중인 도서를 다시 대여하거나, 대여되지 않은 도서를 반납하는 잘못된 상태 전환을 차단합니다.
6. 대여 상태 변경 뒤 상세정보 딕셔너리도 다시 생성하여 객체 상태와 저장된 상세정보가 어긋나지 않도록 수정했습니다.
