## Todo 체크리스트

입력 폼에서 제목과 내용을 받아 체크박스 목록에 추가하는 Todo 프로젝트입니다.

- HTML 시맨틱 태그와 입력 폼
- CSS 박스 모델과 Flexbox
- JavaScript DOM 선택·생성·수정·삭제
- 체크박스를 이용한 완료 상태 변경
- `data-filter`와 CSS 속성 선택자를 이용한 목록 조회

자세한 실행 방법, 기능 설명, 교안과의 연결은 [프로젝트 README](./todo-checklist/README.md)에 정리되어 있습니다.
