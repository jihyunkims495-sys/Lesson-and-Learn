# 무인양품 메인 화면 클론 — 출처와 구현 범위

- 참고 페이지: [무인양품 한국 공식 온라인스토어](https://mujikorea.co.kr/)
- 확인일: 2026-11-16
- 구현 코드: [HTML](index.html), [CSS](css/style.css)
- 로고·이미지·상품 문구의 출처: 무인양품 공식몰과 해당 페이지가 제공하는 공개 이미지 주소
- 이미지별 원본 URL·파일명·해상도·해시: [이미지 출처 목록](assets/muji/sources.json)

## 재현한 화면

상단 행사 안내, 로고와 내비게이션, 검색 입력, 수납용품 대표 배너, 원형 카테고리 20개, 신상품 카드 6개, 가구·주방 기획 콘텐츠 2개, 고객 안내 푸터를 HTML/CSS로 구성했습니다. 대표 배너는 수납용품 장면 하나로 고정했습니다.

큰 화면의 가로 메뉴·여러 열 상품 배치를 작은 화면의 접이식 메뉴·적은 열 배치로 전환합니다. 검색은 공식몰의 공개 검색 경로에 `keyword`를 전달하는 GET 폼이며, 공식몰 링크와 각 본문 영역으로 이동하는 링크를 구분했습니다.

로고는 공식 SVG, 상품 사진은 공식 WebP, 배너·카테고리 사진은 공식 JPEG/PNG를 사용합니다. 대표 배너의 제목과 설명은 HTML 텍스트로 작성했습니다. 이미지의 픽셀은 변경하지 않았습니다.

이 페이지는 HTML/CSS 학습용 클론입니다. 상품과 행사 내용은 확인일의 화면을 기준으로 하며, 공식 서비스는 위 원본 링크에서 이용할 수 있습니다.
