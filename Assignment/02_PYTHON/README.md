# AX Study

AI Agent 엔지니어 부트캠프에서 학습한 내용을 기록하는 저장소입니다.

Python 기초부터 AI Agent 개발까지 학습 과정을 단계별로 기록하고,
강의 내용과 실습 결과를 함께 정리하고 있습니다.

- 최종적으로 AI Agent 서비스를 직접 설계하고 구현하기

## 현재 학습 포인트

### Chapter 05. 함수

함수를 단순히 정의하고 실행하는 단계에서 확장하여,
함수를 값처럼 전달하거나 다른 함수 안에서 사용하는 구조를 학습하고 있습니다.

- 함수 정의와 호출
- 매개변수와 반환값
- 지역변수와 전역변수, 변수 스코프
- 함수를 변수에 저장하는 구조
- 함수를 인자로 전달하거나 반환하는 고차함수
- 함수를 만들어 반환하는 팩토리 함수
- 다른 함수에 전달되어 실행되는 콜백 함수
- 바깥 함수의 값을 기억하는 클로저
- 자기 자신을 호출하는 재귀함수
- 기존 함수의 동작을 감싸 확장하는 데코레이터
- 짧은 함수를 표현하는 람다 함수
