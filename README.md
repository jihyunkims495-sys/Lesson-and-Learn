## How the archive is organized

```text
Program
└── Week
    ├── README.md                 # 주차 목표와 일자별 목차
    ├── YYYY-MM-DD
    │   ├── 01-preview-notes-*   # 예습 자료
    │   ├── 02-learning-notes-*  # 수업 및 개념 정리
    │   ├── 03-practice-*        # 실습과 문제 해결
    │   └── 04-til-*             # 일일 학습 회고
    └── weekly-retrospective.md  # 주간 회고
```

모든 날짜에 네 종류의 문서가 반드시 존재하는 것은 아닙니다. 해당 날짜에 실제로 수행한 학습 활동만 기록합니다.

## Record types

- **Preview Notes**: 수업 전에 조사한 개념과 질문
- **Learning Notes**: 강의에서 학습한 개념과 예제
- **Practice**: 직접 수행한 실습, 복습, 오류 해결 과정
- **TIL**: 그날 새롭게 이해한 내용과 다음 학습 계획
- **Weekly Retrospective**: 한 주의 성과, 어려움, 개선 방향

## What this repository demonstrates

- 학습 내용을 구조화하고 연결하는 과정
- 이해한 내용과 아직 부족한 부분을 구분하는 자기 점검
- 오류와 시행착오를 문제 해결 기록으로 전환하는 방식
- GitHub를 장기 학습 기록의 Source of Truth로 운영하는 방법
- 반복되는 학습 과정을 향후 자동화와 AI Agent로 발전시키는 과정
