| 강 | 수업 주제 | 예습할 질문 |
|---|---|---|
| 1 | 데이터베이스와 AI 아키텍처 | AI 애플리케이션에서 어떤 데이터를 저장하고 다시 조회할까? |
| 2 | PostgreSQL·Supabase 설정 | 데이터베이스, 서비스, 접속 도구의 역할은 어떻게 다를까? |
| 3 | DDL·CREATE TABLE | 저장할 대상의 속성을 어떤 열과 자료형으로 표현할까? |
| 4 | ALTER·DROP | 테이블 구조 변경과 테이블 삭제는 어떤 차이가 있을까? |
| 5 | 제약조건과 무결성 | 잘못된 데이터가 저장되지 않게 어떤 규칙을 둘까? |
| 6 | 외래 키와 관계 | 서로 다른 테이블의 행을 어떤 기준으로 연결할까? |

## 2장 — 데이터 조작과 트랜잭션

| 강 | 수업 주제 | 예습할 질문 |
|---|---|---|
| 1 | INSERT·샘플 데이터 | 어떤 열에 어떤 값을 넣어야 유효한 행이 될까? |
| 2 | SELECT·조회와 필터링 | 조회할 행의 조건과 출력할 열을 어떻게 구분할까? |
| 3 | UPDATE·상태 변경 | 수정 대상 행과 바꿀 값을 어떻게 지정할까? |
| 4 | DELETE·검증 | 삭제할 대상을 실행 전에 어떻게 확인할까? |
| 5 | TCL·트랜잭션 기초 | 여러 변경을 하나의 작업 단위로 묶어야 하는 상황은 무엇일까? |
| 6 | ACID·ROLLBACK | 작업 중 실패하면 어느 상태까지 되돌아가야 할까? |
| 7 | 통합 데이터 조작 | 생성·조회·수정·삭제가 어떤 순서로 연결될까? |
| 8 | AI 문서 DB 미니 프로젝트 | 문서와 관련 정보를 어떤 테이블·관계로 설계할까? |
