# TIL — CSS Grid와 미디어 쿼리로 반응형 열 구성하기

- 날짜: 2026-09-18
- Level / Week: LV.2 / Week 7
- 범위: 3장 2강 — 반응형 웹, 미디어 쿼리 및 Tailwind CSS

## 오늘 확인한 내용

반응형 레이아웃은 작은 화면의 기본 스타일을 먼저 만들고, 화면이 넓어질 때 미디어 쿼리로 필요한 부분만 덮어쓰는 방식으로 구성할 수 있다. 오늘 실습에서는 CSS Grid를 기본 1열로 두고 태블릿에서는 2열, 데스크톱에서는 3열로 바꾸는 구조를 작성했다.

```css
.box-group {
  display: grid;
  grid-template-columns: 1fr;
}

@media screen and (min-width: 1024px) {
  .box-group {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

`1fr`은 사용 가능한 공간 한 몫을 뜻하고, `repeat(3, 1fr)`은 같은 너비의 열 3개를 만든다. `row-gap`과 `column-gap`을 나눠 사용하면 행과 열 사이 간격을 각각 제어할 수 있다.

## 코드에서 발견한 점

미디어 쿼리는 조건의 뜻뿐 아니라 문법도 정확해야 한다. 수업 파일에는 `and(`처럼 공백 없이 작성된 부분이 있어 `and (` 형태로 확인이 필요하다. 또한 태블릿 시작값이 750px인데, 교안 예습 기준은 768px이었다. 브레이크포인트는 프로젝트마다 달라질 수 있지만 같은 실습 안에서는 어떤 기준을 쓰는지 명확히 해야 한다.
