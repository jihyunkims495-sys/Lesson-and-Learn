## 파일별 확인 기록

### `1.html`

- viewport 메타 태그 포함
- `.box`에 `width: 150px`, `height: 150px`, `background: orange` 지정
- 반응형 조건이 없는 기본 박스 예제

### `2.html`

- `display: grid`와 `grid-template-columns: 1fr`로 기본 1열 구성
- 9개 `.box` 요소를 같은 Grid 컨테이너에 배치
- 태블릿 2열, 데스크톱 3열 전환을 의도한 미디어 쿼리 작성
- `@media print`에서 `body` 배경을 검정으로 바꾸는 규칙 작성

## 정적 검토에서 발견한 확인 필요 사항

1. 화면용 미디어 쿼리의 `and(`에는 공백이 없다. 표준 문법인 `and (`로 고친 뒤 실제 적용 여부를 확인해야 한다.
2. 태블릿 시작값은 750px이다. 교안 예습 기준 768px과 다른 값이므로 의도된 변경인지 확인이 필요하다.
3. 브라우저 크기 조절과 인쇄 미리보기는 실행하지 않았다. 1열·2열·3열 전환과 인쇄 배경색은 미검증 상태다.
4. 오늘 폴더에는 Tailwind CSS 실습 파일이 없다. Tailwind 실행을 완료한 것으로 기록하지 않는다.
