## HTML과 CSS의 연결

```text
HTML로 콘텐츠의 구조와 의미 작성
→ CSS 선택자로 꾸밀 요소 선택
→ 속성과 값으로 표현 지정
→ 캐스케이드·상속·명시도로 최종 스타일 결정
→ 브라우저가 화면 렌더링
```

HTML이 무엇이 있는지 정한다면 CSS는 그 내용을 어떻게 보여 줄지 정한다. CSS를 적용해도 HTML의 의미 구조가 자동으로 바뀌지는 않는다.

## CSS 기본 문법

```css
h1 {
  color: blue;
  font-size: 2rem;
}
```

| 구성 | 예 | 역할 |
|---|---|---|
| 선택자 | `h1` | 스타일을 적용할 요소 선택 |
| 속성 | `color` | 변경할 스타일 종류 |
| 값 | `blue` | 속성에 적용할 설정 |
| 선언 | `color: blue;` | 속성과 값의 한 쌍 |
| 선언 블록 | `{ ... }` | 선택자에 적용할 선언 모음 |

CSS 주석은 `/* 내용 */` 형식이다. HTML 문서의 일반 영역에서 CSS 주석을 사용하면 주석이 아니라 화면 텍스트로 해석될 수 있으므로 작성 위치를 구분한다.

## CSS 적용 방법

| 방법 | 위치 | 특징 |
|---|---|---|
| 인라인 | 요소의 `style` 속성 | 한 요소에 빠르게 적용하지만 재사용하기 어려움 |
| 내부 스타일 | `head`의 `style` 요소 | 한 HTML 문서 안에서 관리 |
| 외부 스타일 | 별도 `.css` 파일 | 구조와 표현을 분리하고 여러 문서에서 재사용 |

```html
<link rel="stylesheet" href="css/style.css">
```

외부 CSS가 적용되지 않으면 `href`의 상대 경로, 파일명과 확장자, 저장 여부를 먼저 확인한다.

## 기본 선택자

```css
* { box-sizing: border-box; }
p { color: gray; }
.notice { background-color: yellow; }
#main-title { color: navy; }
```

- `*`: 모든 요소
- `p`: 같은 태그를 찾는 타입 선택자
- `.notice`: 같은 클래스를 공유하는 요소를 찾는 클래스 선택자
- `#main-title`: 고유 ID를 가진 요소를 찾는 ID 선택자

클래스는 반복되는 디자인에 재사용하고 ID는 문서 안의 고유한 요소를 식별할 때 사용한다.

## 관계 선택자

```text
A B  → A 안에 있는 모든 자손 B
A > B  → A의 바로 아래 자식 B
A + B  → A 바로 다음에 있는 형제 B 하나
A ~ B  → A 뒤에 있는 같은 부모의 형제 B 모두
```

관계 선택자는 오른쪽의 실제 선택 대상부터 확인하고 왼쪽으로 이동하며 부모·자식·형제 관계를 검사한다.

## 가상 클래스와 가상 요소

```css
a:hover { color: red; }
input:focus { border-color: blue; }
input:checked + label { font-weight: bold; }
.title::before { content: "★ "; }
```

- 가상 클래스 `:`는 상태, 조건, 구조적 위치를 선택한다.
- 가상 요소 `::`는 요소의 일부나 생성된 표현 영역을 선택한다.
- `:nth-child()`는 모든 형제 중 순서를, `:nth-of-type()`은 같은 태그 유형끼리의 순서를 센다.

중요한 콘텐츠를 `::before`나 `::after`의 `content`에만 넣으면 접근성 도구에서 일관되게 전달되지 않을 수 있다. 핵심 내용은 HTML에 작성한다.

## 캐스케이드·명시도·상속

여러 규칙이 같은 요소에 적용되면 선언 출처와 중요도, 선택자의 명시도, 선언 순서 등을 비교해 최종 값을 정한다.

입문 단계의 기본 명시도 순서는 다음처럼 이해할 수 있다.

```text
인라인 스타일 > ID > 클래스·가상 클래스 > 타입·가상 요소 > 전체 선택자
```

명시도가 같다면 일반적으로 나중에 선언된 규칙이 우선한다. `!important`는 우선순위를 강제로 높이므로 충돌을 해결하는 기본 방법으로 반복하기보다 선택자 범위와 구조를 먼저 점검한다.

`color`와 `font-family`처럼 일부 속성은 부모에서 자식으로 상속되지만 배경, 테두리, 간격 같은 모든 속성이 자동 상속되는 것은 아니다.

## 텍스트와 배경

- `font-family`: 글꼴과 대체 글꼴 목록
- `font-size`: 글자 크기
- `font-weight`: 글자 굵기
- `line-height`: 한 줄의 높이
- `text-align`: 블록 안 인라인 콘텐츠 정렬
- `color`: 글자색
- `background-color`: 배경색
- `background-image`: 배경 이미지나 그라데이션
- `background-size: cover`: 영역을 채우지만 일부가 잘릴 수 있음
- `background-size: contain`: 이미지를 전부 보이지만 빈 공간이 생길 수 있음

`px`는 직관적인 CSS 픽셀, `em`은 해당 요소의 계산 맥락, `rem`은 루트 요소의 글자 크기를 기준으로 한다.
