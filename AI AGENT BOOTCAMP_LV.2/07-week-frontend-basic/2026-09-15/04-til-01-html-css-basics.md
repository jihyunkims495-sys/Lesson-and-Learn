## 오늘 배운 핵심

프론트엔드는 사용자가 웹사이트에서 직접 보고 조작하는 화면 영역이다. 그 화면에서 HTML은 내용의 **구조와 의미**를 만들고 CSS는 색상, 크기, 간격처럼 **보이는 방식**을 정한다.

UI는 사용자가 만나는 화면과 조작 경험 전체를 뜻한다. CSS는 그 UI의 모양을 구현하는 기술 중 하나이므로 UI와 CSS는 같은 말이 아니다.

```text
HTML = 무엇이 있는지와 각 내용의 역할
CSS  = 그 내용을 어떻게 보이게 할지
UI   = 사용자가 실제로 보고 조작하는 전체 화면과 방식
```

브라우저와 서버는 HTTP라는 요청·응답 규칙으로 통신한다. HTTPS는 이 통신을 암호화한 방식이다.

## HTML에서 정리한 것

태그는 제목, 문단, 링크, 이미지처럼 콘텐츠의 역할을 표시한다. 모든 태그를 한꺼번에 외우기보다 자주 쓰는 태그의 역할과 선택 기준을 익히고, 세부 문법은 필요할 때 문서에서 확인하는 편이 중요하다.

- `div`는 여러 요소를 블록 단위로 묶을 때 사용한다.
- `span`은 문장 일부를 줄바꿈 없이 묶어 스타일이나 동작을 적용할 때 사용한다.
- `a`의 `href`는 이동할 주소를, `img`와 `video`의 `src`는 가져올 파일의 위치를 나타낸다.
- `form` 안의 입력값은 `name`을 기준으로 서버에 전달되고 `value`로 선택값을 구분할 수 있다.
- `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`는 영역의 의미를 드러낸다.

HTML은 연속된 일반 공백을 하나로 합쳐 표시한다. 줄을 바꿀 때는 내용상 줄바꿈이면 `br`, 입력한 모양을 보존해야 하면 `pre`, 화면 간격을 조절할 때는 CSS를 사용한다. `&nbsp;`를 여러 번 반복해 배치를 맞추는 방법은 유지보수하기 어렵다.

VS Code에서는 `!`를 입력한 뒤 Tab을 누르면 Emmet이 HTML 기본 문서 구조를 생성해 준다.

## CSS에서 정리한 것

CSS는 `선택자 { 속성: 값; }` 형태로 작성한다. HTML에 적용하는 방법은 외부 스타일 시트, 문서 안의 `style`, 요소의 `style` 속성 세 가지가 있다.

```css
.notice {
  color: blue;
}
```

선택자는 스타일을 적용할 HTML 요소를 찾는 조건이다.

- `p`: 모든 `p` 요소를 찾는 타입 선택자
- `.notice`: 같은 `class`를 가진 요소들을 찾는 클래스 선택자
- `#title`: 특정 `id`를 가진 요소를 찾는 ID 선택자
- `A B`: A 안에 있는 모든 B를 찾는 자손 선택자
- `A > B`: A의 바로 아래 자식 B를 찾는 자식 선택자
- `A + B`: A 바로 다음의 형제 B를 찾는 인접 형제 선택자
- `A ~ B`: A 뒤에 있는 같은 부모의 형제 B들을 찾는 일반 형제 선택자

여러 CSS 규칙이 같은 요소에 적용되면 선택자의 구체성, 선언 위치와 작성 순서 등을 함께 비교해 최종 스타일이 정해진다. `!important`는 우선순위를 강제로 높이므로 기본 해결 방법처럼 반복해서 사용하지 않는다.
