## 수업에서 연결한 전체 구조

```text
브라우저가 서버에 HTTP 요청
→ HTML을 받아 문서 구조와 의미 해석
→ CSS 선택자로 요소를 찾아 표현 적용
→ 사용자가 보고 조작할 UI 렌더링
```

- 프론트엔드는 사용자가 직접 보고 조작하는 화면 영역이다.
- HTTP는 브라우저와 서버가 요청과 응답을 주고받는 규칙이다.
- HTML은 제목·문단·링크·폼처럼 콘텐츠의 구조와 역할을 정한다.
- CSS는 색상·크기·간격·배치처럼 화면 표현을 정한다.
- UI는 사용자가 만나는 화면과 조작 방식 전체이며 CSS는 UI를 구현하는 기술 중 하나다.

## HTML 학습 내용

### 기본 문서와 텍스트

HTML 요소는 보통 시작 태그, 내용, 종료 태그로 구성되고 시작 태그에는 속성을 추가할 수 있다. 제목은 크기보다 문서 위계에 맞춰 `h1`~`h6`을 선택한다.

`div`와 `span`은 모두 의미 없는 묶음이지만 기본 배치가 다르다. `div`는 블록 단위, `span`은 문장 흐름 안의 일부를 묶는다. 문장 일부의 색상을 바꾸거나 JavaScript 제어 대상으로 지정할 때 `span`을 사용할 수 있다.

### 링크·미디어·상대 경로

`a`의 `href`는 이동할 주소를 지정하고 `img`·`video`의 `src`는 현재 문서에 불러올 자원의 위치를 지정한다. 상대 경로는 HTML 파일의 위치에서 출발해 해석한다.

링크 실습에서는 `_blank`, 이름이 지정된 iframe, `_parent`, `_top`을 사용해 문서가 열리는 위치를 비교했다. 이미지·비디오 실습에서는 파일 경로와 크기, 재생 컨트롤을 작성했다.

### 폼

폼 데이터는 입력 요소의 `name`이 키가 되고 입력값 또는 `value`가 값이 되어 전달된다. `id`는 문서 안에서 요소를 식별하고 `label`의 `for`와 연결하는 데 사용한다.

radio는 하나만 선택할 그룹에, checkbox는 여러 항목을 선택할 때 사용한다. 같은 범주의 선택지는 같은 `name`으로 묶고 서로 다른 `value`로 구분한다.

### 시멘틱 구조

`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`를 이용해 콘텐츠의 역할을 드러냈다. 시멘틱 태그는 구조의 의미를 전달하고 CSS는 해당 영역의 모양을 별도로 정한다.

## CSS 학습 내용

CSS는 외부 파일, `head`의 내부 스타일, 요소의 인라인 스타일로 연결할 수 있다. 실습에서는 세 방식을 한 문서에서 비교했다.

타입·클래스·ID 선택자가 같은 요소에 적용될 때는 각 선택자의 구체성과 선언 위치를 확인해야 한다. 자손·자식 선택자는 포함 관계를, `+`와 `~`는 같은 부모를 둔 형제 관계를 기준으로 선택한다.

```text
A B   모든 하위 B
A > B 바로 아래 B
A + B 바로 다음 B 하나
A ~ B 뒤에 있는 형제 B들
```

`!important`가 붙은 선언도 실습했지만, 실제 스타일 관리에서는 충돌 원인을 먼저 찾고 선택자와 구조를 단순하게 유지하는 것이 중요하다.
