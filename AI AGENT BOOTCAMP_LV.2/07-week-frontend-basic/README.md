> 2026-09-15 시작 · LV.2

HTML로 웹 문서의 구조와 의미를 만들고 CSS로 화면의 표현을 제어하는 기초를 학습하는 주차입니다.

## Learning goals

- HTML 기본 문서 구조와 자주 사용하는 태그의 역할 이해
- 링크·이미지·폼·미디어·시멘틱 태그의 사용 목적 구분
- CSS를 연결하는 세 가지 방법과 기본 문법 이해
- 타입·클래스·ID·관계 선택자가 가리키는 요소 구분
- 속성·상태 선택자와 상대 단위, 박스 모델의 계산 방식 이해
- Flexbox의 `justify-content` 값에 따른 공간 분배 결과 구분
- 작성한 코드를 브라우저에서 확인하고 잘못된 경로·속성·문서 구조 점검
