## 1. 객체 리터럴

객체는 관련된 값을 프로퍼티로 묶어 관리한다. 프로퍼티는 키와 값으로 구성하며 점 표기법 또는 대괄호 표기법으로 접근한다.

```javascript
const product = {
  name: "셔츠",
  price: 39000,
  stock: 12
};

product.name;
product["price"];
```

- 점 표기법: 키 이름을 코드에 직접 작성할 때 사용한다.
- 대괄호 표기법: 키가 변수에 들어 있거나 공백·특수문자가 포함될 때 사용할 수 있다.
- 객체는 참조 타입이므로 다른 변수에 대입할 때 같은 객체를 함께 가리킬 수 있다.

## 2. 배열과 배열 메서드

배열은 여러 값을 순서대로 저장하며 인덱스는 0부터 시작한다.

```javascript
const prices = [39000, 59000, 79000];

prices[0];
prices.length;
```

배열 메서드를 확인할 때는 이름만 외우지 않고 입력, 반환값, 원본 배열 변경 여부를 함께 살핀다.

| 메서드 | 역할 | 반환값 확인 포인트 |
|---|---|---|
| `map()` | 각 요소를 변환 | 변환 결과로 새 배열을 만드는가 |
| `filter()` | 조건에 맞는 요소 선택 | 선택 결과로 새 배열을 만드는가 |
| `reduce()` | 요소를 하나의 값으로 누적 | 누적값의 초기값은 무엇인가 |
| `some()` | 하나라도 조건을 만족하는지 확인 | 불리언을 반환하는가 |
| `every()` | 모두 조건을 만족하는지 확인 | 불리언을 반환하는가 |

```javascript
const discountedPrices = prices.map(function (price) {
  return price * 0.9;
});
```

`map()`에 전달한 함수는 배열의 각 요소를 처리하는 콜백 함수다.

## 3. 구조 분해와 전개

구조 분해 할당은 배열이나 객체에서 필요한 값을 꺼내 변수에 담는다.

```javascript
const [firstPrice, secondPrice] = prices;
const { name, price } = product;
```

전개 문법은 배열이나 객체의 요소를 펼쳐 복사하거나 결합할 때 사용한다.

```javascript
const copiedProduct = { ...product };
const copiedPrices = [...prices];
```

전개 문법으로 만든 복사는 한 단계만 복사하는 얕은 복사다. 중첩 객체가 있으면 내부 참조가 남을 수 있다.

## 5. 함수 정의와 호출

함수는 정의만 해서는 본문이 실행되지 않는다. 함수 이름 뒤에 `()`를 붙여 호출해야 실행된다.

```javascript
function calculateDiscount(price, rate) {
  const discount = price * rate;
  return price - discount;
}

const result = calculateDiscount(39000, 0.1);
```

| 용어 | 의미 |
|---|---|
| 함수 정의 | 실행할 코드를 함수로 만든 것 |
| 함수 호출 | `()`를 사용해 함수 실행을 시작하는 것 |
| 매개변수 | 함수가 값을 받을 자리 |
| 인수 | 함수를 호출할 때 전달하는 실제 값 |
| 반환값 | 함수가 호출 위치로 돌려주는 결과 |

### 실행 순서

```text
1. calculateDiscount 함수를 정의
2. calculateDiscount(39000, 0.1)을 호출
3. 39000과 0.1이 매개변수 price와 rate에 전달
4. 함수 본문을 위에서 아래로 실행
5. return으로 계산 결과 반환
6. 반환값을 result에 저장
7. 호출한 위치의 다음 코드로 이동
```

## 6. 함수 표현식과 일급 객체

JavaScript의 함수는 값처럼 변수에 저장하고 다른 함수에 전달하거나 함수에서 반환할 수 있다.

```javascript
const calculateDiscount = function (price, rate) {
  return price - price * rate;
};
```

함수를 값처럼 다룰 수 있기 때문에 콜백 함수와 고차 함수를 만들 수 있다.

## 7. 콜백 함수

콜백 함수는 다른 함수에 인수로 전달되어 필요한 시점에 호출되는 함수다.

```javascript
function printResult(value, formatter) {
  console.log(formatter(value));
}

function addWon(value) {
  return `${value}원`;
}

printResult(39000, addWon);
```

`addWon`은 함수 자체를 전달하고, `addWon()`은 함수를 즉시 호출한 결과를 전달한다는 차이가 있다.

## 8. 호출 스택과 함수 실행 흐름

함수가 호출되면 실행 중인 함수 정보가 호출 스택에 쌓인다. 함수 실행이 끝나면 스택에서 제거되고 이전 호출 위치로 돌아간다.

```javascript
function outer() {
  inner();
}

function inner() {
  return "완료";
}

outer();
```

```text
전역 코드
→ outer() 호출
→ inner() 호출
→ inner() 종료
→ outer()로 복귀
→ outer() 종료
→ 전역 코드로 복귀
```

## 9. 클로저

클로저는 함수가 선언될 때의 바깥 변수 환경을 기억하여, 바깥 함수 실행이 끝난 뒤에도 그 변수에 접근할 수 있게 하는 구조다.

```javascript
function createCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}

const counter = createCounter();
counter();
counter();
```

반환된 내부 함수가 `count`를 계속 참조하기 때문에 호출할 때마다 상태가 이어진다.
