## 1. What — 무엇을 배웠는가?

### 학습 범위

- 프론트엔드 개발 4장 3강: 객체 리터럴, 배열 및 내장 객체

### 핵심 개념

- 객체는 키와 값으로, 배열은 인덱스 순서로 데이터를 관리한다.
- 배열 메서드는 입력, 반환값과 원본 변경 여부를 함께 확인해야 한다.
- 함수는 정의만으로 실행되지 않고 `()`를 사용해 호출해야 실행된다.
- 매개변수는 함수가 값을 받을 자리이고, 인수는 호출할 때 전달하는 실제 값이다.
- 콜백 함수는 다른 함수에 전달되어 필요한 시점에 호출되는 함수다.
- 클로저는 함수가 선언될 때의 바깥 변수 환경을 기억하는 구조다.

### 오늘 가장 중요했던 학습

JavaScript에는 함수와 메서드가 많기 때문에 모든 이름을 외우는 방식만으로는 실제 개발에 적용하기 어렵다. 오늘은 필요한 기능을 MDN 공식 문서에서 찾고 다음 항목을 확인하는 방법을 배웠다.

```text
처리할 데이터 확인
→ 관련 객체나 메서드 검색
→ Syntax 확인
→ Parameters 확인
→ Return value 확인
→ 원본 변경 여부 확인
→ Example 확인
```

특히 배열 메서드는 비슷해 보여도 반환값과 원본 배열 변경 여부가 다를 수 있으므로 문서를 끝까지 확인해야 한다.

- 메서드가 요구하는 인수와 반환값을 확인해 잘못된 사용을 줄일 수 있다.

## 3. How — 함수는 어떻게 작동하는가?

### 기본 실행 과정

```text
함수 정의
→ 함수 호출
→ 인수 전달
→ 매개변수에 값 저장
→ 함수 본문 실행
→ return으로 값 반환
→ 호출한 위치로 복귀
```

```javascript
function calculateDiscount(price, rate) {
  const discount = price * rate;
  return price - discount;
}

const result = calculateDiscount(39000, 0.1);
```

위 코드는 다음 순서로 작동한다.

1. `calculateDiscount` 함수를 정의한다.
2. `calculateDiscount(39000, 0.1)`을 호출한다.
3. `39000`과 `0.1`이 `price`와 `rate`에 전달된다.
4. 함수 본문에서 할인 금액을 계산한다.
5. `return`으로 계산 결과를 호출 위치에 돌려준다.
6. 반환된 값을 `result`에 저장한다.

### 아직 이해가 부족한 부분

함수가 언제 만들어지고 언제 실행되는지, 함수 안의 값이 어떻게 움직이는지, `return` 이후 실행 위치가 어디로 돌아가는지가 아직 완전히 연결되지 않았다. 콜백, 호출 스택과 클로저를 이해하려면 먼저 이 기본 흐름을 확실히 익혀야 한다.

- 브라우저 콘솔과 VS Code를 계속 오가면서 현재 어떤 코드를 확인하는지 놓치기 쉬웠다.
- 코드 작성 순서와 실제 함수 실행 순서를 구분하기 어려웠다.
- 함수가 값을 반환한 뒤 어느 위치에서 실행이 이어지는지 이해하기 어려웠다.

### 실행 근거

- 브라우저 콘솔과 VS Code를 오가며 학습했다.
- 구체적인 코드, 출력 결과, 오류 메시지와 해결 과정은 남아 있지 않다.
- 따라서 별도의 실습 완료나 오류 해결 결과로 기록하지 않는다.
