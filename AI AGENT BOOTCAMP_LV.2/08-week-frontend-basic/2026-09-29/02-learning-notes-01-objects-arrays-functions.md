- Level / Week: LV.2 / Week 8

## 핵심 성과

오늘의 가장 중요한 학습은 많은 함수 이름을 외우는 것이 아니라, MDN 공식 문서에서 필요한 함수와 메서드를 찾고 사용 조건을 확인하는 방법을 익힌 것이다.

## MDN 활용 순서

1. 다루는 값이 Array, Object, Function 중 무엇인지 확인한다.
2. 관련 MDN 참고서에서 메서드를 검색한다.
3. Syntax로 호출 형태를 확인한다.
4. Parameters와 Return value를 확인한다.
5. 배열 메서드는 원본 변경 여부를 확인한다.
6. Example을 한 실행 환경에서 재현한다.
7. 브라우저 기능이면 Browser compatibility를 확인한다.

## 객체와 배열

- 객체는 키와 값, 배열은 인덱스 순서로 데이터를 관리한다.
- 객체와 배열은 참조 타입이므로 복사할 때 참조 공유 여부를 확인해야 한다.
- `map`, `filter`, `reduce`, `some`, `every`는 콜백으로 처리 규칙을 전달한다.
- 배열 메서드는 이름보다 입력·출력·원본 변경 여부로 비교하는 것이 유용하다.

## 함수

- 함수는 정의만으로 실행되지 않으며 호출 연산자 `()`가 있어야 실행된다.
- 매개변수는 정의할 때의 입력 자리, 인수는 호출할 때 전달하는 실제 값이다.
- 함수는 값으로 전달할 수 있으므로 콜백으로 사용할 수 있다.
- 콜백은 다른 함수가 필요한 시점에 호출하는 함수다.
- 호출 스택은 함수의 실행과 복귀 순서를 관리한다.
- 클로저는 함수가 선언 당시의 바깥 변수 환경을 기억하는 구조다.

## 어려웠던 점과 보강 방향

- 키워드가 많아 관계를 잡기 어려웠다.
- 브라우저 콘솔과 VS Code를 오가며 실행 흐름을 유지하기 어려웠다.
- 함수가 생성되고 호출되어 반환한 뒤 원래 위치로 돌아오는 흐름이 명확하지 않았다.
- 다음 학습에서는 한 실행 환경만 사용하고 함수 한 개의 흐름을 `정의 → 호출 → 인수 → 본문 → return → 복귀`로 추적한다.

## 실행 근거

브라우저 콘솔과 VS Code를 사용해 학습했지만 구체적인 코드·출력·오류 해결 기록은 남아 있지 않다. 따라서 실행 완료나 실습 성공으로 확정하지 않는다.
