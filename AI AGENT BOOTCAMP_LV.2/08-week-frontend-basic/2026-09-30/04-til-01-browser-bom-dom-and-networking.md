## 무엇을 배웠는가?

오늘 프론트엔드 개발 6장 전체를 학습했다. 1강에서는 브라우저가 HTML을 읽고 화면을 만드는 과정과 BOM을, 2강에서는 DOM 객체 트리를 탐색하고 문서의 요소를 동적으로 제어하는 방법을 배웠다.

- 브라우저는 HTML 요소를 JavaScript가 다룰 수 있는 DOM 객체로 만든다.
- `window`는 브라우저 탭의 최상위 객체이고 `document`는 HTML 문서를 표현한다.
- `body`, `div`, `span`은 HTML 요소이며, 브라우저가 해석한 뒤 각 요소에 대응하는 DOM 객체가 생긴다.
- HTML 속성은 태그에 작성한 설정이고, DOM 프로퍼티는 객체가 가진 현재 정보다.
- 메서드는 객체가 수행할 수 있는 기능이다.
- `data-*`는 요소와 함께 보관하는 추가 데이터이며 JavaScript에서는 `dataset`으로 읽는다.
- `data-price`의 `price`는 고정된 이름이 아니라 개발자가 목적에 맞게 정한 이름이다.

```html
<input type="text" id="input" data-price="10000">
```

```javascript
const input = document.querySelector("#input");

console.log(input.value);         // 사용자가 입력한 값
console.log(input.dataset.price); // "10000"
```

`type="text"`는 글자 입력창을 만들고, `data-price`는 JavaScript가 필요할 때 읽을 추가 데이터를 저장한다. 현재 코드에서 이 데이터를 사용하는 JavaScript가 없다면 화면이나 기능에는 아무 변화가 없다.

## 오늘 어려웠던 점

요소와 객체, 속성과 프로퍼티, 그리고 이를 제어하는 메서드의 종류가 많아 한 번에 관계를 잡기 어려웠다. 특히 HTML에 작성한 태그가 언제 DOM 객체가 되는지, `data-price`가 왜 화면에 보이지 않는지, `dataset`의 이름이 정해져 있는지 계속 헷갈렸다.

```text
HTML 요소       → 화면을 구성하는 부품
HTML 속성       → 태그에 작성한 설정과 추가 정보
DOM 객체        → 브라우저가 요소를 JavaScript로 다룰 수 있게 만든 표현
DOM 프로퍼티    → 객체가 가진 현재 값
DOM 메서드      → 객체가 수행할 수 있는 기능
```

수업 예제를 VS Code에 하나씩 입력하면서 평소 사용하던 웹과 앱의 화면이 코드로 구성되고 움직이는 모습을 확인한 것이 신기했다. 다만 메서드가 다양해 반복해서 직접 선택하고 변경해보는 복습이 꼭 필요하다고 느꼈다.
