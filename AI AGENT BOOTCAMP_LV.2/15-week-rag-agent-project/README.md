# Week 15 — Project 3 RAG Agent

> 기간: 2026-11-23 ~ 2026-11-27

지난주에 학습한 RAG 파이프라인을 팀 프로젝트에 적용합니다. 문서 수집·정제·청킹부터 Vector Search, Hybrid Search, Re-ranking, 근거 기반 답변과 평가까지 하나의 흐름으로 연결합니다.

## 학습 목표

- 실제 사용자의 질문과 해결할 문제를 먼저 정의한다.
- 구조화 데이터와 검색 문서의 역할을 분리한다.
- 청크와 메타데이터를 원문 근거까지 추적할 수 있게 설계한다.
- Vector, Hybrid, Hybrid + Re-ranking 결과를 같은 조건에서 비교한다.
- 답변 가능 질문과 근거가 부족한 질문을 포함한 평가셋을 만든다.
