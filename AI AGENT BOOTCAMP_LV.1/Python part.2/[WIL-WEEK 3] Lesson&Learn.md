# Lesson&Learn

> **개념은 점점 많아져 카오스가 커졌지만, 완성된 코드를 읽고 실행 흐름과 변수의 역할을 따라가는 힘은 조금씩 생기기 시작한 주였다.**

---

## 1. 이번 주 학습 흐름

- 시작: 클래스와 객체지향을 배우면서 `class`, 객체, 속성, 메서드, `self`, `__init__()`이 한꺼번에 등장해 기존의 함수·변수 개념과 섞이기 시작했다.
- 중간: 예외 처리와 디버깅을 통해 코드가 실패했을 때 `try → except`, Traceback, Breakpoint, Variables를 이용해 문제 위치와 실행 흐름을 추적하는 방법을 익혔다.
- 마무리: 내장 함수와 표준 라이브러리를 배우면서 모든 로직을 직접 `for`와 `if`로 작성하지 않아도 된다는 관점이 생겼고, 파일·JSON·Pandas·비동기처럼 Python이 실제 데이터와 외부 작업을 다루는 영역까지 학습 범위가 넓어졌다.
- 이번 주 가장 큰 변화: **코드를 처음부터 만드는 능력은 아직 약하지만, 이미 작성된 코드에서 변수의 값과 실행 순서를 읽고 역할을 구분하려는 힘이 이전보다 커졌다.**

| 클래스 | 새로운 문법 하나처럼 느껴졌다. | 관련된 속성과 기능을 하나로 묶는 설계도라는 큰 역할은 이해했다. |
| 예외 처리와 디버깅 | 오류가 나면 코드가 잘못된 것으로만 느껴졌다. | 예외 처리는 실패 상황에 대한 대응을 정하는 것이고, 디버깅은 실패 원인을 추적하는 별도의 과정이라는 구분이 생겼다. |
| 내장 함수·라이브러리 | 문제를 풀려면 `if`, `for`, `while`을 직접 조합해야 한다고 생각했다. | Python이 이미 제공하는 함수와 라이브러리를 먼저 찾고 조합하는 것도 문제 해결 방법이라는 관점이 생겼다. |

| 개념 | 헷갈리는 부분 | 다음에 확인할 것 |
| --- | --- | --- |
| 클래스·객체·함수·메서드·변수 | 각각의 정의보다 코드 안에서 서로 어떤 관계인지가 계속 섞인다. | 아주 작은 클래스 예제로 `class → 객체 → 속성 → 메서드` 흐름을 다시 추적한다. |
| `self`, `name`, `self.name`, `__init__()` | 형태는 읽을 수 있지만 객체 생성 시 실제 값이 어떻게 연결되는지 아직 불안정하다. | 객체 생성 한 번을 기준으로 값이 어디서 들어와 어디에 저장되는지 확인한다. |
| `raise`와 예외 전달 | `return`과 다른 역할은 이해했지만 함수 안에서 발생한 예외가 바깥 `except`까지 전달되는 흐름은 아직 어렵다. | 짧은 함수 하나와 `try-except`만 있는 예제로 반복한다. |
| 변수 설계 | 반복 변수, 매개변수, 결과 변수, 인덱스 변수, 예외 객체 변수가 각각 전혀 다른 종류처럼 느껴진다. | 변수마다 `이름 → 값의 출처 → 현재 값 → 사용 목적`을 적으며 읽는다. |

## 3. KPT 주간 회고

### Keep — 계속할 것

- 이번 주에 잘한 점: 개념이 계속 쌓여 혼란스러운 상황에서도 모르는 부분을 억지로 이해했다고 넘기지 않고 끝까지 학습을 이어갔다.
- 이해하는 데 도움이 된 학습 방법: 코드 한 줄을 볼 때 `이 값은 어디서 왔는가?`, `지금 어떤 예외가 발생할 수 있는가?`, `이 함수는 어떤 반복을 대신하는가?`처럼 역할 중심으로 질문한 방식이 도움이 됐다.
- 다음 주에도 유지할 습관: 모르는 용어나 문법이 나오면 바로 외우기보다 이미 아는 개념과 연결하고, 실행 흐름을 먼저 확인한다.

### Problem — 개선할 것

- 이해하기 어려웠던 부분: 함수 → 클래스 → 예외 처리 → 라이브러리로 빠르게 범위가 넓어지면서 앞선 개념이 완전히 안정되기 전에 다음 구조가 계속 추가됐다.
- 반복해서 실수한 부분: 변수의 역할이 바뀔 때마다 새로운 종류의 개념처럼 느껴지고, 코드 구조가 깊어지면 들여쓰기와 실행 범위를 함께 추적하기 어렵다.
- 아직 혼자 설명하기 어려운 부분: 클래스와 객체의 관계, `self`, `raise`, 여러 함수 사이의 예외 전달, 처음부터 필요한 변수를 설계하는 과정.
- 시간을 비효율적으로 사용한 부분: 한 번에 모든 문법과 예외적인 동작까지 기억하려고 할 때 학습 부담이 커졌다.

### Try — 다음 주에 시도할 것

- 다시 공부할 내용: `class → 객체 → 속성 → 메서드`, 변수 역할, `raise → except`, Traceback 읽기.
- 예제를 보지 않고 시도해볼 것: 속성 1개와 메서드 1개인 클래스, 짧은 `try-except`, 간단한 내장 함수 선택 문제.
- 새롭게 시도할 학습 방법: 문제를 바로 코드로 바꾸지 않고 먼저 `입력값 → 필요한 변수 → 처리 → 결과`를 글로 적은 뒤 코드와 연결한다.
- 줄이거나 하지 않을 것: 함수와 라이브러리 이름을 전부 외우려는 방식, 한 번의 학습으로 개념을 완전히 이해해야 한다는 접근.

## 6. 이번 주 한 줄 회고

### 가장 중요하게 배운 것

> Python은 모든 것을 직접 처음부터 만드는 언어가 아니라, 이미 있는 함수와 도구를 이해하고 적절하게 연결해서 쓰는 것도 중요한 문제 해결 방식이다.

### 가장 어려웠던 것

> 변수, 함수, 클래스, 객체, 예외가 한 코드 안에서 동시에 움직일 때 각각의 역할을 놓치지 않고 따라가는 것.
