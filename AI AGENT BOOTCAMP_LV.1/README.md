# AI Agent Bootcamp — Level 1

> Git과 Python 기초부터 AI Literacy, Machine Learning, SQL까지 학습한 6주 과정입니다.

이 디렉터리는 강의 내용을 보관하는 데서 그치지 않고, 예습부터 학습, 실습, 일일 회고(TIL), 주간 회고까지 이어지는 학습 과정을 기록합니다.

## Curriculum

| Week | Topic | Period | Key learning |
|---:|---|---|---|
| 01 | [Git & GitHub](./01-week-git-github/) | 2026-08-04 ~ 2026-08-07 | Git 동작 원리, 브랜치, 원격 저장소, 협업 |
| 02 | [Python Basics](./02-week-python-basics/) | 2026-08-10 ~ 2026-08-14 | 실행 환경, 자료형, 제어문, 함수, 모듈 |
| 03 | [Python Advanced](./03-week-python-advanced/) | 2026-08-18 ~ 2026-08-21 | 객체지향, 예외 처리, 표준 라이브러리, 비동기, 파일 입출력 |
| 04 | [AI Literacy & Machine Learning](./04-week-ai-literacy-machine-learning/) | 2026-08-24 ~ 2026-08-28 | 생성형 AI, 프롬프트, 데이터 분석, 회귀, PyTorch |
| 05 | [Machine Learning & SQL](./05-week-machine-learning-sql/) | 2026-08-31 ~ 2026-09-04 | DNN, RNN, LSTM, Transformer, 데이터베이스 기초 |
| 06 | [SQL](./06-week-sql/) | 2026-09-07 ~ | 조회, 집계, JOIN, 서브쿼리 |

## 기록 읽는 법

날짜별 디렉터리의 문서는 다음 순서로 정렬됩니다.

| Prefix | Record type | Description |
|---:|---|---|
| `01` | Preview Notes | 수업 전에 조사하고 정리한 내용 |
| `02` | Learning Notes | 강의에서 배운 개념과 예제 |
| `03` | Practice | 복습, 프롬프트, 코드 및 문제 해결 기록 |
| `04` | TIL | 그날 새롭게 이해한 내용과 개인 회고 |

각 주차의 `weekly-retrospective.md`에는 한 주의 학습 결과, 어려웠던 점, 다음 학습 계획이 정리되어 있습니다.

## 추천 탐색 순서

1. 위 Curriculum에서 관심 있는 주차를 선택합니다.
2. 주차별 README에서 일자별 학습 주제를 확인합니다.
3. 상세 개념은 Learning Notes에서 확인합니다.
4. 학습자의 이해 과정과 시행착오는 TIL과 Weekly Retrospective에서 확인합니다.
