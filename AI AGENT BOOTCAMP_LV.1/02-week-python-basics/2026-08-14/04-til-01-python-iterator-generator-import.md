## 1. What — 무엇을 배웠는가?

### 핵심 개념

- Iterable
- Iterator와 `iter()`, `next()`
- Generator와 `yield`
- Python 표준 라이브러리
- `import`
- `from`
- `as`
- `datetime`

### 핵심 코드

> 아직 예제를 보지 않고 직접 작성할 수 있는 코드는 없다. 아래 코드는 오늘 배운 개념을 복습하기 위한 최소 예시다.

```python
# iterable과 iterator
numbers = [1, 2, 3]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

```python
# generator
def number_generator():
    yield 1
    yield 2
    yield 3
```

```python
# 모듈 전체 가져오기
import datetime

print(datetime.datetime.now())
```

```python
# 모듈 안에서 필요한 대상 가져오기
from datetime import datetime

print(datetime.now())
```

```python
# 별칭 사용하기
import datetime as dt
```

## 2. Why — 왜 필요한가?

### 이 개념이 필요한 이유

- 데이터를 반복해서 처리할 때 Python 내부에서 어떤 방식으로 값을 하나씩 꺼내는지 이해할 수 있다.
- 필요한 기능을 매번 처음부터 직접 만들지 않고 Python에서 이미 제공하는 기능을 가져와 사용할 수 있다.
- 표준 라이브러리와 외부 라이브러리를 활용하면 기존 기능을 조합하고 가공하여 새로운 프로그램을 만들 수 있다.
- 개발은 모든 코드를 혼자 만드는 것이 아니라 이미 만들어진 도구를 이해하고 적절하게 활용하는 과정이기도 하다는 것을 알게 되었다.

### 내 생각

> 오늘 가장 신기했던 것은 고유한 기능을 매번 처음부터 개발하는 것이 아니라 이미 공개되어 있는 모듈을 가져와서 내가 필요한 방향으로 가공하고 조합할 수 있다는 점이었다.
>
> Python 표준 라이브러리에 생각보다 훨씬 많은 모듈이 있다는 것도 신기했다.
>
> 아직 `import 모듈.기능` 형태와 `from`, `as` 등이 머릿속에서 명확하게 구분되지는 않지만, 앞으로 다른 사람이나 Python이 이미 만들어 놓은 기능을 가져와 활용하는 일이 개발에서 중요하겠다는 생각이 들었다.

## 3. How — 어떻게 작동하는가?

### 작동 과정

#### Iterable과 Iterator

1. 리스트, 문자열처럼 하나씩 순회할 수 있는 대상이 있다.
2. `iter()`를 이용하면 해당 값을 하나씩 꺼낼 수 있는 Iterator를 얻을 수 있다.
3. Iterator에 `next()`를 호출하면 값을 순서대로 하나씩 가져온다.

#### Generator

1. 함수 안에서 `yield`를 사용한다.
2. `yield`에서 값을 하나 반환하고 실행을 잠시 멈춘다.
3. 다음 값을 요청하면 이전에 멈췄던 위치부터 다시 실행한다.

#### import

1. Python에서 사용할 모듈을 가져온다.
2. 모듈 안에 만들어져 있는 기능을 사용한다.
3. 필요하면 `from`으로 특정 기능을 가져오거나 `as`로 별칭을 지정한다.

### 내 말로 설명하기

> 아직 iterable, iterator, generator 세 가지를 내 말로 완전히 설명할 수 없다.
>
> 지금 이해한 정도는 Iterator에 `iter()`, `next()`가 있다는 것이고, Generator는 Iterator와 관련된 개념이며 `yield`를 이용해 함수 실행을 중간에 멈췄다가 다시 이어갈 수 있다는 정도다.
>
> Iterable은 처음에는 '변수인가?'라고 생각했지만, 복습하면서 리스트나 문자열처럼 하나씩 순회할 수 있는 대상을 의미한다는 것을 다시 확인했다.
>
> 세 개의 관계는 아직 머릿속에서 짬뽕되어 있기 때문에 다시 공부해야 한다.
