# TIL | 2026-08-12 | Python 종합 제어 실습

> **조건을 고르고, 반복하고, 값을 기억하면 코드의 구조가 보이기 시작한다.**

> 조건문과 반복문을 언제 쓰는지는 이해했지만, 문제를 처음 받았을 때 필요한 변수를 몇 개 만들어야 하는지와 코드를 빈 화면에서 직접 설계하는 부분이 아직 어렵다는 것을 확인했다.

---

## 1. What — 무엇을 배웠는가?

### 종합 제어의 핵심

- `for`는 여러 데이터를 하나씩 꺼내기 위해 사용한다.
- `if`는 꺼낸 값이 원하는 조건에 맞는지 검사한다.
- `total = 0`은 합계를 누적하기 위한 시작값이다.
- `count = 0`은 조건을 만족한 개수를 누적하기 위한 시작값이다.
- `total += number`는 값 자체를 누적한다.
- `count += 1`은 조건을 만족한 횟수를 누적한다.
- 최댓값·최솟값은 실제 데이터의 첫 번째 값을 최초 비교 기준으로 잡을 수 있다.
- 평균은 반복이 끝난 뒤 합계와 데이터 개수를 이용해 한 번 계산한다.
- `while True`는 종료 시점을 미리 알 수 없을 때 사용하고, 원하는 조건에서 `break`로 종료할 수 있다.
- 일반 `while`도 조건에 사용되는 값이 바뀌지 않으면 무한 루프가 발생할 수 있다.

### 오늘 가장 중요하게 이해한 구조

```text
문제
↓
무엇을 반복할지 찾기
↓
어떤 조건을 검사할지 찾기
↓
무엇을 기억해야 할지 찾기
↓
필요한 변수 만들기
↓
코드 작성
```

---

## 2. Why — 왜 필요한가?

조건문과 반복문을 조합하면 같은 코드를 길게 반복 작성하지 않고도 여러 데이터를 효율적으로 처리할 수 있다.

내가 이해한 핵심은 다음과 같다.

> 조건에 맞을 때와 맞지 않을 때의 흐름을 나누고, 반복을 통해 여러 데이터를 처리하면 긴 코드를 더 효율적으로 구조화할 수 있다.

다만 현재는 코드를 보면 이해할 수 있지만, 문제를 처음 받고 어떤 변수와 구조가 필요한지 스스로 설계하는 것은 아직 어렵다.

그래서 앞으로는 바로 코드를 쓰려고 하기보다 **문제를 한국어 실행 순서로 먼저 나누는 연습**이 필요하다.

---

## 3. How — 어떻게 작동하는가?

### 조건에 맞는 값의 개수를 세기

```python
numbers = [3, 15, 20, 5]
count = 0

for number in numbers:
    if number > 10:
        count += 1
```

실행 흐름:

```text
count = 0

3  → False → count = 0
15 → True  → count = 1
20 → True  → count = 2
5  → False → count = 2
```

여기서 `count += 1`은 숫자 자체를 더하는 것이 아니라 **조건을 만족한 횟수**를 하나씩 누적한다.

### 최고 점수와 총합을 동시에 구하기

```python
scores = [80, 95, 70]

highest = scores[0]
total = 0

for score in scores:
    if score > highest:
        highest = score

    total += score
```

변수 역할:

```text
scores   → 원본 데이터
score    → 현재 반복에서 꺼낸 값
highest  → 현재까지의 최고 점수
total    → 현재까지의 총합
```

## 4. 오늘 헷갈렸던 부분

### 1) 첫 번째 비교가 False인데 `highest`가 왜 남아 있는가?

```python
highest = numbers[0]
```

에서 이미 첫 번째 값이 저장되어 있다.

첫 반복에서:

```python
5 > 5
```

가 `False`여도 `highest`를 지우는 코드가 실행되는 것이 아니다.  
단지 `highest = number`로 **갱신하지 않을 뿐 기존 값 5는 그대로 유지**된다.

정리:

> `highest = numbers[0]`은 최초 기준값 설정이고, 반복문 안의 `highest = number`는 더 큰 값을 발견했을 때 기준값을 교체하는 코드다.

---

### 2) 평균은 왜 `average = 0`으로 시작하지 않는가?

`total`은 반복할 때마다 계속 사용되므로 시작값이 필요하다.

```python
total = 0
```

반면 평균은 반복이 끝난 뒤:

```python
average = total / len(numbers)
```

로 한 번 계산해 처음 저장한다.

따라서 `average = 0`으로 미리 만들 필요가 없다.

---

### 3) 개수를 세는데 왜 복합 대입 연산자를 사용하는가?

처음에는 `+=`가 합계를 계산할 때만 사용하는 것으로 생각했다.

하지만 개수도:

```text
0개 → 1개 → 2개 → 3개
```

처럼 이전 개수에 1을 계속 더해 저장하는 **누적**이다.

```python
count += 1
```

은:

```python
count = count + 1
```

과 같다.

---

### 4) `len()`은 언제 쓰는가?

처음에는 10보다 큰 숫자의 개수를 구할 때 `len()`을 사용하면 된다고 생각했다.

하지만:

```python
len(numbers)
```

은 조건과 관계없이 원래 리스트의 **전체 요소 개수**를 센다.

따라서 특정 조건을 만족한 값의 개수는:

```python
count = 0

for number in numbers:
    if number > 10:
        count += 1
```

처럼 직접 세는 방식이 더 적절하다.

정리:

| 목적 | 사용 |
|---|---|
| 리스트 전체 요소 수 | `len()` |
| 조건을 만족한 요소 수 | `count += 1` |

---

### 5) 문제를 보고 변수가 2개인지 3개인지 헷갈림

가장 중요한 발견이었다.

처음부터 변수 개수를 정하려고 하면 더 헷갈린다.

먼저 **프로그램이 무엇을 기억해야 하는지** 찾는다.

예:

> `[80, 95, 70]`에서 최고 점수와 총합을 구한다.

결과로 기억해야 하는 값:

```text
최고 점수 → highest
총합 → total
```

반복을 위해 필요한 값:

```text
원본 데이터 → scores
현재 꺼낸 값 → score
```

즉 결과 변수는 2개지만, 코드에서는 원본 데이터와 반복 변수까지 추가될 수 있다.

> **변수 개수를 먼저 정하지 말고, 기억해야 하는 값을 먼저 찾는다.**

---

### 6) `break`가 실행되면 직전 값도 사라지는가?

```python
count = 0

while True:
    count += 1

    if count == 3:
        break
```

실행 순서는:

```text
count = 2
↓
count += 1
↓
count = 3
↓
3 == 3 → True
↓
break
```

따라서 최종 `count`는 3이다.

`break`는 저장된 값을 되돌리는 것이 아니라 **그 시점부터 반복만 종료한다.**

---

### 7) 일반 `while`에서도 무한 루프가 생기는 이유

```python
count = 1

while count <= 3:
    print(count)
```

`count`를 변경하는 코드가 없으므로:

```text
1 <= 3 → True
1 <= 3 → True
1 <= 3 → True
...
```

가 계속 반복된다.

무한 루프의 원인은 변수가 전역변수인지 여부가 아니라, **조건식이 계속 True인데 조건에 사용되는 값이 변하지 않는 것**이다.
