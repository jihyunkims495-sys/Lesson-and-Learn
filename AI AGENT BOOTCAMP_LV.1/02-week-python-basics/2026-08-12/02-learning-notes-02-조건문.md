# [Python] 조건문 학습정리

## 1. 오늘의 학습 목표

- 조건문이 왜 필요한지 설명할 수 있다.
- `if`, `elif`, `else`의 역할을 구분할 수 있다.
- 조건문이 위에서 아래로 어떤 순서로 실행되는지 설명할 수 있다.
- 들여쓰기가 왜 중요한지 설명할 수 있다.
- 여러 조건이 있을 때 조건의 순서가 왜 중요한지 이해할 수 있다.
- `and`, `or`를 사용해 여러 조건을 결합할 수 있다.

---

## 2. 조건문이란?

조건문은 **조건의 결과가 True인지 False인지에 따라 실행할 코드를 선택하는 문법**이다.

일반적인 파이썬 코드는 위에서 아래로 순서대로 실행된다.

하지만 실제 프로그램에서는 상황에 따라 다른 행동을 해야 한다.

예를 들어:

- 나이가 20세 이상이면 성인 인증
- 로그인 상태라면 마이페이지 표시
- 점수가 90점 이상이면 A학점
- 재고가 있으면 주문 가능

이처럼 프로그램이 상황을 판단하고 서로 다른 코드를 실행할 수 있도록 만드는 것이 조건문이다.

---

## 3. if 문

### 기본 구조

```python
if 조건식:
    실행할 코드
```

`if` 뒤의 조건식이 `True`이면 들여쓰기된 코드가 실행된다.

조건식이 `False`이면 해당 코드는 실행하지 않고 건너뛴다.

### 예제

```python
age = 25

if age >= 20:
    print("성인입니다.")

print("프로그램 종료")
```

### 실행 순서

1. `age` 변수에 `25`를 저장한다.
2. `age >= 20`을 계산한다.
3. `25 >= 20`은 `True`이다.
4. `if` 아래의 `"성인입니다."`를 출력한다.
5. `if` 문이 끝난 뒤 `"프로그램 종료"`를 출력한다.

출력 결과:

```text
성인입니다.
프로그램 종료
```

### 핵심

`print("프로그램 종료")`는 들여쓰기가 되어 있지 않으므로 `if`에 포함되지 않는다.

따라서 조건과 관계없이 실행된다.

---

## 4. 콜론(:)과 들여쓰기

### 콜론(:)

조건식 뒤에는 반드시 `:`을 작성한다.

```python
if age >= 20:
```

콜론은 **이제부터 이 조건에 속한 코드 블록이 시작된다는 표시**이다.

### 들여쓰기

파이썬은 중괄호 `{}` 대신 들여쓰기로 코드의 소속을 구분한다.

일반적으로 공백 4칸을 사용한다.

```python
if age >= 20:
    print("성인")
```

위 코드에서 `print("성인")`은 `if`에 속한다.

반면:

```python
if age >= 20:
    print("성인")

print("종료")
```

`print("종료")`는 들여쓰기가 없기 때문에 `if`에 속하지 않는다.

### 들여쓰기 오류

같은 블록의 들여쓰기 깊이가 다르면 `IndentationError`가 발생할 수 있다.

```python
if True:
    print("첫 번째")
   print("두 번째")
```

## 5. if-else

조건이 참일 때와 거짓일 때 각각 다른 코드를 실행하고 싶다면 `else`를 사용한다.

### 구조

```python
if 조건식:
    True일 때 실행
else:
    False일 때 실행
```

### 예제

```python
age = 17

if age >= 20:
    print("성인")
else:
    print("미성년자")
```

### 실행 순서

1. `age`에 `17`을 저장한다.
2. `age >= 20`을 검사한다.
3. `17 >= 20`은 `False`이다.
4. `if` 블록을 건너뛴다.
5. `else` 블록을 실행한다.
6. `"미성년자"`가 출력된다.

### 핵심

`if-else`에서는 둘 중 **하나의 블록만 실행된다.**

---

## 6. if-elif-else

조건이 세 가지 이상일 때 `elif`를 사용할 수 있다.

### 구조

```python
if 조건1:
    실행 코드
elif 조건2:
    실행 코드
else:
    실행 코드
```

### 예제

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

### 실행 순서

1. `score`에 `85` 저장
2. `score >= 90` 검사 → `False`
3. 다음 `score >= 80` 검사 → `True`
4. `"B"` 출력
5. 조건문 종료
6. 아래 `else`는 실행하지 않음

### 가장 중요한 규칙

`if-elif-else`는 **위에서 아래로 조건을 검사하다가 처음으로 True가 된 블록 하나만 실행하고 종료한다.**

---

## 7. 조건 순서가 중요한 이유

다음 코드를 보자.

```python
score = 95

if score >= 80:
    print("B")
elif score >= 90:
    print("A")
```

`score`가 95이면 두 조건 모두 참이다.

하지만 첫 번째 조건인:

```python
score >= 80
```

이 먼저 `True`가 된다.

따라서 `"B"`를 출력하고 조건문이 종료된다.

아래의 `score >= 90`은 검사하지 않는다.

### 올바른 순서

```python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

범위가 겹치는 조건은 일반적으로 **더 높은 기준 또는 더 구체적인 조건부터 위에 작성**해야 한다.

## 8. 여러 조건을 함께 검사하기

### and

`and`는 양쪽 조건이 모두 `True`일 때만 전체 결과가 `True`가 된다.

```python
age = 25
has_ticket = True

if age >= 20 and has_ticket:
    print("입장 가능")
else:
    print("입장 불가")
```

각 조건은:

```text
age >= 20  → True
has_ticket → True
```

따라서:

```text
True and True → True
```

결과는 `"입장 가능"`이다.

### and의 결과

| 왼쪽 | 오른쪽 | 결과 |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

### or

`or`는 둘 중 하나 이상이 `True`이면 전체 결과가 `True`가 된다.

```python
is_admin = False
is_manager = True

if is_admin or is_manager:
    print("접근 가능")
```

`False or True`이므로 결과는 `True`이다.

## 9. 중첩 조건문

조건문 안에 또 다른 조건문을 작성할 수도 있다.

```python
is_logged_in = True
has_permission = True

if is_logged_in:
    if has_permission:
        print("관리자 대시보드 진입")
```

하지만 조건이 단순하다면 `and`를 사용해 한 줄로 표현할 수 있다.

```python
if is_logged_in and has_permission:
    print("관리자 대시보드 진입")
```

조건문을 너무 많이 중첩하면 들여쓰기가 깊어져 코드를 읽기 어려워질 수 있다.

---

## 10. 반드시 알아야 할 내용

지금 단계에서 반드시 이해해야 하는 것은 다음과 같다.

- `if`는 조건이 `True`일 때 실행된다.
- `else`는 앞의 조건이 `False`일 때 실행된다.
- `elif`는 앞 조건이 `False`일 때 다음 조건을 검사한다.
- `if-elif-else`는 위에서 아래로 검사한다.
- 처음 `True`가 나온 블록 하나만 실행한다.
- 파이썬에서는 들여쓰기가 코드의 소속을 결정한다.
- 범위가 겹치는 조건은 순서가 중요하다.
- `and`는 모든 조건이 참일 때만 참이다.
- `or`는 하나 이상의 조건이 참이면 참이다.

## 12. 자주 실수하는 부분

### 실수 1. 들여쓰기가 없는 코드를 if에 포함된 것으로 생각하기

```python
if age >= 20:
    print("성인")

print("종료")
```

`print("종료")`는 조건과 관계없이 실행된다.

### 실수 2. 여러 조건이 True이면 모두 실행된다고 생각하기

```python
number = 15

if number > 5:
    print("5보다 큼")
elif number > 10:
    print("10보다 큼")
```

`number > 10`도 참이지만 첫 번째 `if`가 먼저 참이므로 `"5보다 큼"`만 출력된다.

### 실수 3. 넓은 조건을 먼저 작성하기

```python
if score >= 80:
    print("B")
elif score >= 90:
    print("A")
```

95점도 첫 번째 조건에서 걸리므로 `"B"`가 출력된다.
