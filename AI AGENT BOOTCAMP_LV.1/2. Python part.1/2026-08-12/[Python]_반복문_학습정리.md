## 1. 반복문이란?

반복문은 같은 코드를 여러 번 실행해야 할 때 사용하는 문법이다.

예를 들어 과일 리스트의 값을 하나씩 출력하고 싶을 때 `print()`를 여러 번 직접 쓰는 대신 반복문을 사용할 수 있다.

```python
fruits = ["사과", "바나나", "체리"]

for fruit in fruits:
    print(fruit)
```

실행 흐름:

```text
1회차 → fruit = "사과" → 출력
2회차 → fruit = "바나나" → 출력
3회차 → fruit = "체리" → 출력
```

### 핵심

`for 변수 in 여러값:`은 여러 값에서 하나씩 꺼내어 변수에 저장하면서 반복한다.

---

## 2. for 문

`for`문은 리스트, 튜플, 문자열처럼 여러 값이 있거나 반복 횟수가 정해져 있을 때 사용한다.

### 기본 구조

```python
for 변수 in 반복할_데이터:
    실행할 코드
```

예시:

```python
fruits = ["사과", "바나나", "체리"]

for fruit in fruits:
    print(fruit)
```

여기서:

- `fruits` : 여러 값을 가지고 있는 리스트
- `fruit` : 반복할 때마다 리스트 요소 하나가 저장되는 변수

---

## 3. range() 함수

`range()`는 주로 `for`문과 함께 사용하며 반복에 사용할 정수 범위를 만든다.

### 3.1 range(끝값)

```python
for i in range(5):
    print(i)
```

`range(5)`가 만드는 값:

```text
0, 1, 2, 3, 4
```

주의할 점:

`5`는 마지막으로 출력되는 숫자가 아니라 **범위의 끝값**이며, 끝값은 포함하지 않는다.

---

### 3.2 range(시작값, 끝값)

```python
for i in range(2, 6):
    print(i)
```

결과:

```text
2
3
4
5
```

규칙:

- 시작값은 포함
- 끝값은 포함하지 않음

즉,

```text
range(2, 6)
→ 2, 3, 4, 5
```

---

### 3.3 range(시작값, 끝값, 증감폭)

```python
for i in range(1, 8, 2):
    print(i)
```

결과:

```text
1
3
5
7
```

실행 흐름:

```text
1 → 3 → 5 → 7
```

다음 값은 `9`지만 끝값 `8`을 넘어가기 때문에 반복이 종료된다.

### 한 줄 요약

`range(시작, 끝, 증감폭)`은 시작값부터 끝값 미만까지 증감폭만큼 이동한다.

---

## 4. while 문

`while`문은 반복 횟수보다 **조건**을 기준으로 반복할 때 사용한다.

### 기본 구조

```python
while 조건식:
    실행할 코드
```

예시:

```python
count = 1

while count <= 3:
    print(count)
    count += 1
```

실행 순서:

```text
count = 1
→ 1 <= 3 : True
→ 1 출력
→ count = 2

count = 2
→ 2 <= 3 : True
→ 2 출력
→ count = 3

count = 3
→ 3 <= 3 : True
→ 3 출력
→ count = 4

count = 4
→ 4 <= 3 : False
→ 반복 종료
```

### 핵심

`while`문은 반복할 때마다 조건식을 다시 검사한다.

---

## 5. 무한 루프

`while True`를 사용하지 않아도 조건식이 계속 `True`라면 무한 루프가 발생할 수 있다.

예시:

```python
count = 1

while count <= 3:
    print(count)
```

이 코드에서 `count` 값은 반복 중에 변하지 않는다.

따라서:

```text
count = 1
1 <= 3 → True
1 출력

다시 조건 검사
count는 여전히 1

1 <= 3 → True
1 출력
...
```

계속 반복된다.

### 중요한 점

무한 루프의 원인은 `while True`라는 문법 자체가 아니라 **조건식이 영원히 False가 되지 않는 것**이다.

### 안전하게 종료하려면

조건에 사용되는 값을 반복문 안에서 변화시켜야 한다.

```python
x = 5

while x > 0:
    print(x)
    x -= 1
```

실행 흐름:

```text
5 → 4 → 3 → 2 → 1 → 0
```

`x`가 `0`이 되면 `x > 0`이 False가 되어 종료된다.

---

## 6. break

`break`는 반복문 전체를 즉시 종료한다.

```python
for num in range(1, 6):
    if num == 4:
        break
    print(num)
```

실행 흐름:

```text
num = 1 → 출력
num = 2 → 출력
num = 3 → 출력
num = 4 → break
반복문 종료
```

결과:

```text
1
2
3
```

`4`에서 `break`가 실행되므로 이후의 `4`, `5`는 출력되지 않는다.

### 한 줄 요약

`break` = 지금 돌고 있는 반복문을 끝낸다.

---

## 7. continue

`continue`는 반복문 전체를 끝내지 않는다.

현재 회차의 아래쪽 코드만 건너뛰고 다음 반복으로 이동한다.

```python
for num in range(1, 6):
    if num == 3:
        continue
    print(num)
```

실행 흐름:

```text
num = 1 → 출력
num = 2 → 출력
num = 3 → continue → print() 건너뜀
num = 4 → 출력
num = 5 → 출력
```

결과:

```text
1
2
4
5
```

### break와 continue 비교

| 키워드 | 역할 |
|---|---|
| `break` | 반복문 전체 종료 |
| `continue` | 현재 회차만 건너뛰고 다음 반복 진행 |

---

## 8. 중첩 반복문

반복문 안에 또 다른 반복문이 들어있는 구조를 중첩 반복문이라고 한다.

```python
for i in range(2):
    for j in range(3):
        print(i, j)
```

`range(2)`:

```text
0, 1
```

`range(3)`:

```text
0, 1, 2
```

실행 흐름:

```text
i = 0
    j = 0 → print(0, 0)
    j = 1 → print(0, 1)
    j = 2 → print(0, 2)

i = 1
    j = 0 → print(1, 0)
    j = 1 → print(1, 1)
    j = 2 → print(1, 2)
```

총 실행 횟수:

```text
바깥 반복 2번 × 안쪽 반복 3번 = 총 6번
```

### 핵심

바깥쪽 반복문이 한 번 실행될 때마다 안쪽 반복문은 처음부터 끝까지 다시 실행된다.

---

## 9. 중첩 반복문에서 break

```python
for i in range(2):
    for j in range(2):
        if j == 1:
            break
        print(i, j)
```

실행 흐름:

```text
i = 0
    j = 0 → 출력
    j = 1 → break → 안쪽 반복문 종료

i = 1
    j = 0 → 출력
    j = 1 → break → 안쪽 반복문 종료
```

출력 횟수는 총 2번이다.

### 중요한 규칙

`break`는 모든 반복문을 한꺼번에 종료하지 않는다.

**자신을 감싸고 있는 가장 가까운 반복문 하나만 종료한다.**

---

## 10. 중첩 반복문에서 continue

```python
for i in range(2):
    for j in range(3):
        if j == 1:
            continue
        print(i, j)
```

실행 흐름:

```text
i = 0
    j = 0 → 출력
    j = 1 → continue
    j = 2 → 출력

i = 1
    j = 0 → 출력
    j = 1 → continue
    j = 2 → 출력
```

출력 결과:

```text
(0, 0)
(0, 2)
(1, 0)
(1, 2)
```

총 4번 출력된다.

---

## 11. for 문과 while 문 비교

| 구분 | for | while |
|---|---|---|
| 기준 | 데이터 또는 반복 횟수 | 조건 |
| 종료 방식 | 데이터를 모두 순회하면 자동 종료 | 조건이 False가 되면 종료 |
| 주의점 | 범위 설정 | 조건값을 변화시키지 않으면 무한 루프 가능 |
| 대표 사용 | 리스트 순회, 정해진 횟수 반복 | 사용자 입력 대기, 특정 조건이 만족될 때까지 반복 |

### 선택 기준

반복 횟수가 명확하거나 데이터 전체를 순회한다면 `for`.

언제 끝날지 모르고 특정 조건이 만족될 때까지 반복해야 한다면 `while`.

## 12. 반드시 알아야 할 내용

지금 반드시 이해해야 하는 내용:

1. `for`문은 여러 값을 하나씩 꺼내며 반복한다.
2. `range()`의 끝값은 포함하지 않는다.
3. `while`문은 조건이 True인 동안 반복한다.
4. `while`문에서는 조건에 사용되는 값이 변하는지 확인해야 한다.
5. `break`는 반복문 전체를 종료한다.
6. `continue`는 현재 회차만 건너뛴다.
7. 중첩 반복문의 총 실행 횟수는 기본적으로 `바깥 반복 횟수 × 안쪽 반복 횟수`로 생각할 수 있다.
8. 중첩 반복문의 `break`는 가장 가까운 반복문 하나만 종료한다.

## 15. 최종 확인 문제

```python
for i in range(2):
    for j in range(3):
        if j == 1:
            continue
        print(i, j)
```

`print(i, j)`는 총 몇 번 실행되는가?

1. 2번
2. 3번
3. 4번
4. 6번

정답: **3번, 4번**

이유:

각 `i`마다 `j = 0, 1, 2`가 실행되지만 `j = 1`에서는 `continue`가 실행되어 출력되지 않는다.

따라서:

```text
i = 0 → 2번 출력
i = 1 → 2번 출력

총 4번
```
