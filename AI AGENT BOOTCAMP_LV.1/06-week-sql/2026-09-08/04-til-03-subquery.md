# TIL — 비교 기준을 만드는 서브쿼리

> 2026-09-08 · AI AGENT BOOTCAMP LV.1 · Week 06 SQL

## 오늘의 핵심

WHERE는 조건에 맞는 행을 고르고 SELECT는 결과에 보여줄 컬럼을 정한다. 가격으로 상품을 골라도 상품명만 출력할 수 있다.

비교 기준이 고정 숫자가 아니라 전체 평균이라면, 안쪽 SELECT로 평균을 구해 바깥 WHERE에서 사용한다. AVG(price)는 계산 표현식이며, 서브쿼리로 구성할 때는 SELECT와 FROM을 함께 작성한다.

## 오늘 해 본 것

- 전체 상품 평균이 비교 기준임을 찾고 AVG에 넣을 컬럼과 FROM의 테이블을 채웠다.
- 가격이 20,000·80,000·20,000원인 표에서 평균보다 비싼 상품을 재킷으로 예측했다.
- SELECT에 price를 추가하면 재킷의 이름과 80,000원이 함께 표시된다고 예측했다.

문제 풀이는 표와 코드를 읽고 예상한 결과다. 실제 DB 실행 기록은 없다.

## 수업 중 정리한 개념

레코드는 행 한 건이고 p.product_id는 별칭 p의 컬럼을 가리킨다. 스칼라·인라인 뷰·상관은 각각 결과 형태·사용 위치·외부 참조를 기준으로 구분한다. SELECT 1은 상수를 반환하고 EXISTS는 행의 존재를 판단한다.

상세 설명은 [학습 정리](./02-learning-notes-03-subquery.md), 작성 과정은 [문제 풀이](./03-practice-03-subquery.md)에 남겼다.

## 다음 복습과 실습

1. 조건 컬럼과 출력 컬럼을 다른 고객 조회 문제로 구분한다.
2. 평균 서브쿼리를 빈칸 없이 작성하고 결과를 예측한다.
3. 상품·재고 예제로 별칭, 외부 참조, EXISTS를 연결해 읽는다.
4. 고객별 합계 인라인 뷰에서 한 행의 의미를 설명하고 세 종류를 비교한다.
5. PostgreSQL에서 예측 결과를 실제 출력과 비교한다.
