> 머신러닝 모델을 바로 만드는 것이 아니라, 먼저 데이터를 확인하고 정리하고 시각화하면서 데이터의 상태를 이해하는 과정이 필요하다는 것을 배웠다.

## 1. What — 무엇을 배웠는가?

### 핵심 개념

- 머신러닝은 사람이 모든 규칙을 직접 작성하기보다 **데이터에서 패턴을 학습하도록 하는 방법**이다.
- 과적합(Overfitting)은 학습 데이터에는 너무 잘 맞지만 새로운 데이터에서는 성능이 떨어지는 상태다.
- EDA에서는 데이터를 바로 모델에 넣기 전에 구조, 기초 통계, 결측치, 중복, 분포 등을 먼저 확인한다.
- 평균은 데이터의 중심을 보여주지만 데이터가 얼마나 퍼져 있는지는 설명하지 못한다.
- 분산과 표준편차는 데이터가 평균을 기준으로 얼마나 퍼져 있는지 보여준다.
- 결측치는 자료형과 데이터 의미에 따라 평균, 중앙값, 최빈값, `ffill()`, `bfill()` 등을 고려해 처리한다.
- `df.loc`은 `df.loc[행, 열]` 구조로 읽어야 한다.
- Matplotlib의 `Figure`는 전체 도화지이고 `Axes`는 그 안의 각각의 그래프 영역이다.

### 핵심 코드

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 데이터 불러오기
df = sns.load_dataset('titanic')

# 데이터 확인
df.head()
df.info()
df.describe()

# 결측치 확인
df.isnull().sum()

# 범주형 결측치 처리
mode_embarked = df['embark_town'].mode()[0]
df['embark_town'] = df['embark_town'].fillna(mode_embarked)

# 중복 확인
df.duplicated().sum()

# 히스토그램
plt.figure(figsize=(8, 8))
plt.hist(df['fare'], bins=10)
plt.show()
```

### 오늘 수행한 실습

- Seaborn의 타이타닉 데이터를 DataFrame으로 불러왔다.
- `head()`, `info()`, `describe()`로 데이터 구조와 통계를 확인했다.
- `age`, `embarked`, `deck`, `embark_town` 등의 결측치를 확인했다.
- 숫자형과 범주형 데이터의 결측치 처리 방법 차이를 확인했다.
- `mode()`, `fillna()`, `ffill()`, `bfill()`을 사용했다.
- `duplicated()`로 중복 데이터를 확인했다.
- `fare`의 평균과 중앙값을 확인하고 히스토그램을 그렸다.
- `plt.subplots(1, 3)`으로 Figure와 여러 Axes를 만드는 구조를 실습했다.
- `NameError`, `AttributeError`, `loc` 인덱싱 오류를 직접 수정했다.

## 2. Why — 왜 필요한가?

### 이 개념이 필요한 이유

머신러닝은 데이터를 넣는다고 바로 제대로 학습되는 것이 아니다.

데이터에 결측치나 중복이 있거나 특정 값에 지나치게 치우쳐 있으면 통계나 모델 학습 결과가 왜곡될 수 있다.

그래서 먼저 다음 과정을 거쳐야 한다.

```text
데이터 불러오기
↓
구조 확인
↓
통계 확인
↓
결측치 / 중복 확인
↓
데이터 정제
↓
시각화
↓
데이터 특징 이해
↓
머신러닝 학습 준비
```

### 내 생각

> 엑셀에서도 평균을 내고 결측치를 확인하고 그래프를 그릴 수 있어서 아직 Python이 무조건 더 편하다는 느낌까지는 들지 않았다.
>
> 그래도 코드 몇 줄로 데이터 전체를 확인하고, 결측치를 계산하고, 여러 그래프를 한 번에 만드는 과정은 신기했다.
>
> 특히 머신러닝에서는 모델 자체보다 먼저 데이터를 이해하고 정리하는 과정이 필요하다는 점이 인상적이었다.

## 3. How — 어떻게 작동하는가?

### EDA 기본 흐름

```text
df.head()
→ 데이터 일부를 눈으로 확인

df.info()
→ 컬럼 / dtype / Non-Null 확인

df.describe()
→ 평균 / 표준편차 / 사분위수 등 확인

df.isnull().sum()
→ 컬럼별 결측치 수 확인

결측치 처리
→ 데이터 타입과 의미에 맞는 방법 선택

중복 확인
→ duplicated()

시각화
→ histogram / boxplot / scatter 등
```

### 평균, 분산, 표준편차

평균은 데이터의 중심을 보여준다.

분산은 각 값이 평균에서 얼마나 떨어져 있는지를 제곱해서 계산한다. 편차를 그대로 더하면 음수와 양수가 서로 상쇄될 수 있기 때문에 제곱한다.

표준편차는 분산에 제곱근을 적용해 다시 원래 데이터의 단위로 표현한 값이다.

복습 예시:

```text
평균 구매금액 = 80,000원
표준편차 = 120,000원
```

처음에는 "평균보다 큰 금액을 쓰는 유저가 있다"고 생각했지만, 정확히는 **유저별 구매금액 차이가 크고 평균보다 적게 또는 많이 쓰는 유저들이 넓게 퍼져 있을 가능성이 있다**는 의미였다.

### `df.isnull().sum()` 실행 흐름

```text
isnull()
→ 결측치이면 True
→ 값이 있으면 False

sum()
→ True를 1
→ False를 0으로 계산
→ True의 개수를 합산
```

처음에는 결측치의 값을 더한다고 생각했지만 실제로는 **결측치 여부인 `True`의 개수를 세는 것**이었다.

### 범주형 결측치와 최빈값

`embark_town`은 숫자가 아니라 항구 이름을 나타내는 범주형 데이터다.

```text
Southampton
Cherbourg
Queenstown
```

따라서 평균을 낼 수 없고, 가장 자주 등장하는 값인 최빈값을 사용할 수 있다.

```python
mode_embarked = df['embark_town'].mode()[0]
```

다만 범주형 데이터라고 항상 최빈값으로 채우는 것은 아니며, 데이터 의미에 따라 `Unknown` 같은 별도 범주가 더 적절할 수도 있다.

### `df.loc` 구조

```python
df.loc[행, 열]
```

```python
df.loc[:, 'deck']
```

여기서:

```text
:
→ 모든 행

'deck'
→ deck 열
```

즉 모든 행에서 `deck` 컬럼을 선택한다.

실습 중에는 다음처럼 작성했다.

```python
df.loc['deck'] = df['deck'].ffill()
```

이 코드는 `deck` 컬럼을 수정하는 것이 아니라 `deck`이라는 이름의 **행**을 대상으로 하게 된다.

올바른 형태는 다음과 같다.

```python
df['deck'] = df['deck'].ffill()
```

또는:

```python
df.loc[:, 'deck'] = df['deck'].ffill()
```

오늘 기억할 규칙:

```text
df.loc[행, 열]
앞 = 행
뒤 = 열
```

### Figure와 Axes

```python
fig, axes = plt.subplots(1, 3, figsize=(18, 5))
```

이 코드는 그래프 3개를 자동으로 그리는 것이 아니라 3개의 그래프 영역을 준비한다.

```text
Figure
→ 전체 도화지

axes[0]
→ 첫 번째 그래프 영역

axes[1]
→ 두 번째 그래프 영역

axes[2]
→ 세 번째 그래프 영역
```

실습에서는 `axes[0]`에만 히스토그램을 그렸기 때문에 두 번째와 세 번째 영역은 비어 있었다.

## 5. KPT 회고

### Keep — 계속할 것

- 오늘 잘한 점:
  - 에러가 발생했을 때 실행을 포기하지 않고 에러 메시지를 확인하면서 원인을 찾았다.
  - 평균, 표준편차, 결측치 처리처럼 처음 보는 통계 개념을 실제 사용자 구매 데이터 예시와 연결해서 이해하려고 했다.
  - 수업이 끝난 뒤 복습 질문에 직접 답하면서 이해한 부분과 헷갈리는 부분을 구분했다.

- 계속 유지할 학습 방법:
  - 코드를 한 줄씩 실행 흐름으로 읽는다.
  - 함수 이름만 외우기보다 입력 → 처리 → 결과가 어떻게 연결되는지 확인한다.
  - 통계 개념은 실제 사용자/구매 데이터 예시로 바꿔서 생각한다.

### Problem — 개선할 것

- 이해하기 어려웠던 부분:
  - 평균과 표준편차를 숫자로 봤을 때 실제 데이터 분포를 바로 해석하기 어려웠다.
  - 표본분산에서 `n - 1`을 사용하는 이유가 처음에는 직관적으로 이해되지 않았다.
  - `df.loc[행, 열]`에서 행과 열의 위치가 헷갈렸다.
  - Figure와 Axes를 처음에는 모두 '그래프'라고 생각해서 역할이 구분되지 않았다.

- 반복해서 실수한 부분:
  - `df.loc['컬럼명']`을 컬럼 선택이라고 생각하는 실수가 반복되었다.
  - `plt.figuare()`처럼 함수 이름 오타가 있었다.
  - `platform`을 import하지 않고 사용해서 `NameError`가 발생했다.

- 아직 설명하기 어려운 부분:
  - 데이터에 따라 어떤 결측치 처리 방법이 가장 적절한지 판단하는 기준
  - 분산과 표준편차를 실제 분포 모양과 바로 연결해 해석하는 것
  - 표본분산의 `n - 1` 보정을 통계적으로 정확하게 설명하는 것

- 예제를 보지 않고 작성해볼 코드:
