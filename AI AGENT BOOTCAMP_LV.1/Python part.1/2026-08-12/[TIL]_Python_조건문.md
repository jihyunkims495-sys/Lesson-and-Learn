> 조건문은 상황에 따라 실행할 길을 나누고, 반복문은 같은 흐름을 필요한 만큼 다시 실행하게 만드는 제어문이라는 점을 이해했다.

---

## 1. What — 무엇을 배웠는가?

### 조건문 핵심 개념

- `if`는 조건식이 `True`일 때만 해당 코드 블록을 실행한다.
- `elif`는 앞의 조건이 `False`일 때 다음 조건을 검사한다.
- `else`는 앞의 모든 조건이 `False`일 때 실행된다.
- `if-elif-else`는 위에서 아래로 검사하다가 처음 `True`가 나온 블록 하나만 실행한다.
- 파이썬에서는 들여쓰기로 조건문에 포함되는 코드 블록을 구분한다.
- 여러 조건이 겹칠 때는 조건의 순서가 실행 결과에 영향을 줄 수 있다.

### 반복문 핵심 개념

- `for`문은 여러 값을 하나씩 꺼내 반복하거나, `range()`와 함께 정해진 횟수만큼 반복할 때 사용한다.
- `for` 뒤에는 반복 변수가 오며 `i`, `j` 같은 이름이 관례적으로 자주 사용된다.
- `in` 뒤에는 반복할 대상이 오고 숫자 반복에서는 `range()`를 자주 사용한다.
- `range()` 안의 숫자는 변수가 아니라 반복에 사용할 **숫자 범위를 정하는 값**이다.
- `while`문은 뒤에 오는 조건식이 `True`인 동안 하위 코드를 계속 반복한다.
- `while True`가 없어도 조건식이 계속 `True`로 유지되면 무한 루프가 발생할 수 있다.
- `break`는 자신을 감싸고 있는 가장 가까운 반복문 하나를 강제로 종료한다.
- `continue`는 현재 반복 회차의 아래쪽 코드를 건너뛰고 다음 회차로 이동한다.
- 중첩 반복문은 반복문 안에 또 다른 반복문이 있는 구조이며, 바깥 반복이 한 번 돌 때 안쪽 반복이 처음부터 끝까지 다시 돈다.

### 핵심 코드 — 조건문

```python
age = int(input("나이를 입력하세요: "))

if age >= 20:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

### 핵심 코드 — 반복문

```python
for i in range(3):
    print(i)
```

```python
count = 1

while count <= 3:
    print(count)
    count += 1
```

### 오늘 수행한 실습

- `if`, `else`를 이용한 성인 여부 판단

- `and`를 이용해 여러 조건을 동시에 검사하는 코드 확인
- 리스트에서 값을 하나씩 꺼내는 `for`문 실행 흐름 확인
- `range(끝값)`, `range(시작값, 끝값)`, `range(시작값, 끝값, 증감폭)` 확인
- `while`문의 조건식과 종료 조건 확인
- `while True` 없이도 무한 루프가 발생할 수 있는 이유 확인

## 2. Why — 왜 필요한가?

### 조건문이 필요한 이유

- 프로그램이 모든 상황에서 똑같이 동작하는 것이 아니라, 조건에 따라 다른 행동을 하도록 만들 수 있다.
- 사용자가 입력한 값에 따라 결과를 다르게 보여주는 기능을 만들 수 있다.
- 로그인 여부, 권한 여부, 검색 조건, 회원 정보, 주문 가능 여부처럼 실제 서비스에서 자주 발생하는 판단을 코드로 처리할 수 있다.

### 반복문이 필요한 이유

- 같은 코드를 여러 번 직접 작성하지 않고 반복해서 실행할 수 있다.
- 리스트나 문자열처럼 여러 데이터를 처음부터 끝까지 하나씩 처리할 수 있다.
- 반복 횟수가 정해져 있으면 `for`, 특정 조건이 유지되는 동안 반복해야 하면 `while`을 사용할 수 있다.
- 실제 서비스에서는 여러 데이터 처리, 검색 결과 순회, 사용자 입력 재요청, 서버의 반복적인 상태 확인 등 다양한 곳에서 활용할 수 있다.

### 내 생각

> 조건문을 배우면서 실제 서비스에서 정말 많이 사용되겠다는 생각이 들었다.  
> 특히 사용자가 `input`으로 값을 입력하면 그 값을 기준으로 여러 조건을 검사할 수 있기 때문에 로그인 페이지나 검색 페이지처럼 사용자에 따라 다른 결과를 보여줘야 하는 기능에서 많이 쓰일 것 같다.
>
> 처음에는 `if`문 자체가 어렵게 느껴졌는데, 이제는 단순한 `if`문 정도는 코드를 보면 어떤 조건을 검사하고 어떤 코드가 실행되는지 읽을 수 있게 된 것 같아서 뿌듯했다.
>
> 반복문도 처음에는 문법이 길어 보여 복잡했지만, `for`는 반복할 대상을 하나씩 꺼내고 `while`은 조건이 참인 동안 반복한다는 기준으로 나누어 보니 기본 구조는 이해할 수 있게 되었다.
>
> 특히 `range()` 안의 숫자가 변수가 아니라 반복할 숫자 범위를 정하는 값이라는 점을 새롭게 정리했고, `while True`가 없어도 조건식의 값이 바뀌지 않으면 무한 루프가 생길 수 있다는 점이 인상적이었다.

## 3. How — 어떻게 작동하는가?

### 조건문의 작동 과정

1. 프로그램이 조건식을 계산한다.
2. 조건식의 결과가 `True`인지 `False`인지 판단한다.
3. `True`라면 해당 코드 블록을 실행한다.
4. `False`라면 해당 블록을 건너뛰고 다음 `elif` 또는 `else`를 확인한다.
5. `if-elif-else` 구조에서는 처음으로 `True`가 나온 블록 하나를 실행한 뒤 조건문을 종료한다.

### 반복문의 작동 과정 — for

```python
for i in range(3):
    print(i)
```

실행 흐름:

```text
range(3) → 0, 1, 2

i = 0 → 출력
i = 1 → 출력
i = 2 → 출력
반복 종료
```

`i`는 반복할 때마다 값 하나를 받아 저장하는 반복 변수이고, `range(3)`의 `3`은 변수가 아니라 반복 범위의 끝값이다.

### 반복문의 작동 과정 — while

```python
count = 1

while count <= 3:
    print(count)
    count += 1
```

실행 흐름:

```text
count = 1 → 1 <= 3 → True → 출력 → count = 2
count = 2 → 2 <= 3 → True → 출력 → count = 3
count = 3 → 3 <= 3 → True → 출력 → count = 4
count = 4 → 4 <= 3 → False → 종료
```

`while`은 매 회차마다 조건식을 다시 검사하기 때문에 조건식에 사용되는 값이 반복 안에서 바뀌는지 확인해야 한다.

### break와 continue

```python
for num in range(1, 6):
    if num == 3:
        break
    print(num)
```

`break`는 `num == 3`이 되는 순간 가장 가까운 반복문 전체를 종료한다.

```python
for num in range(1, 6):
    if num == 3:
        continue
    print(num)
```

`continue`는 `num == 3`인 회차에서 `print(num)`만 건너뛰고 다음 반복을 계속한다.

### 중첩 반복문

```python
for i in range(2):
    for j in range(3):
        print(i, j)
```

실행 흐름:

```text
i = 0
    j = 0
    j = 1
    j = 2

i = 1
    j = 0
    j = 1
    j = 2
```

바깥 반복 2번 × 안쪽 반복 3번 = 총 6번 실행된다.

### 내 말로 설명하기

> 조건문은 프로그램에게 "이 상황이면 이 코드를 실행하고, 아니면 다른 코드를 실행해"라고 길을 나누어 주는 문법이라고 이해했다.
>
> `for`문은 반복할 값을 하나씩 변수에 넣어가며 실행하는 구조이고, `range()`는 그때 사용할 숫자의 범위를 정해준다. `range()` 안의 숫자 자체가 변수가 아니라는 점을 이번에 확실히 이해했다.
>
> `while`문은 뒤의 조건이 참인 동안 반복한다. 여기서 조건에 사용되는 변수의 값을 바꾸는 코드가 없다면 조건이 계속 참으로 남아 무한 루프가 생길 수 있다. 그래서 꼭 `while True`를 써야만 무한 루프가 되는 것은 아니다.
>
> `break`는 반복문을 끝내고, `continue`는 현재 회차만 건너뛴다.
>
> 중첩 반복문은 조건을 차례대로 고르는 `if-elif-else`와 다르게, 바깥 반복이 한 번 실행될 때 안쪽 반복이 전체 순회하는 구조라고 이해했다.

## 4. 오늘의 문제 해결

### 문제 1 — 조건문의 조건 순서

- 하려고 했던 것: 여러 조건이 모두 `True`일 때 어떤 결과가 나오는지 이해하기
- 발생한 문제: `if`와 `elif`의 조건이 둘 다 `True`이면 두 코드가 모두 실행된다고 생각했다.
- 오류 메시지: 문법 오류가 아니라 실행 흐름에 대한 이해 문제였다.

```python
score = 95

if score >= 80:
    print("B")
elif score >= 90:
    print("A")
```

#### 원인

- `95 >= 80`과 `95 >= 90`이 모두 `True`이므로 두 결과가 모두 출력될 수 있다고 생각했다.
- 하지만 `if-elif-else`는 위에서 아래로 검사하면서 처음 `True`가 나온 블록만 실행한다는 규칙을 놓쳤다.

#### 해결 코드

```python
score = 95

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

#### 해결 원리

> 점수 범위처럼 조건이 서로 겹치는 경우에는 더 높은 기준이나 더 구체적인 조건을 위에 작성해야 한다.

---

### 문제 2 — while True가 없어도 무한 루프가 생기는 이유

처음에는 무한 루프가 `while True`에서만 발생한다고 생각할 수 있었지만, 실제로는 조건식이 계속 `True`로 남아 있으면 일반적인 `while`문에서도 발생한다.

```python
count = 1

while count <= 3:
    print(count)
```

이 코드에서는 `count`를 바꾸는 연산이 없기 때문에 `count`는 계속 `1`이다.

```text
1 <= 3 → True
1 <= 3 → True
1 <= 3 → True
...
```

따라서 무한 루프가 된다.

#### 새롭게 이해한 점

> 무한 루프의 핵심은 `while True`라는 문법이 아니라, **조건식이 계속 False가 되지 않는 상태**라는 것을 이해했다.

---

### 문제 3 — break와 continue 구분

처음에는 `continue`가 `break`처럼 반복을 끝내는 것과 헷갈렸다.

정리하면:

| 키워드 | 실행 결과 |
|---|---|
| `break` | 가장 가까운 반복문 전체 종료 |
| `continue` | 현재 회차의 남은 코드만 건너뛰고 다음 반복 진행 |

`continue`는 아직 실행 흐름이 완전히 익숙하지 않아서 추가 연습이 필요하다.

## 5. KPT 회고

### Keep — 계속할 것

- 단순한 `if`, `if-else`, `if-elif-else` 코드를 보고 실행 결과를 예측할 수 있게 되었다.
- `for`, `range()`, 기본 `while`, `break`, `continue`, 중첩 반복문의 기본 개념을 이해했다.
- 코드를 결과만 외우지 않고 위에서 아래로 한 줄씩 실행 순서를 따라가는 방식이 도움이 되었다.
- 변수에 어떤 값이 저장되는지 직접 적어보는 학습 방법을 계속 유지한다.

### Problem — 개선할 것

- `range()` 안에 어떤 값을 넣어야 원하는 범위가 만들어지는지 아직 헷갈린다.
- `while`의 작동 원리는 이해했지만 실제 서비스에서 어떤 상황에 사용하는지 예시가 더 필요하다.
- `continue`의 실행 흐름이 `break`보다 덜 익숙하다.
- 중첩 반복문은 기본 원리는 이해했지만 코드가 길어지면 실행 순서를 따라가기 어렵다.
- 조건문과 반복문이 함께 사용되면 전체 실행 흐름을 한 번에 파악하기 어렵다.

### Try — 다음에 시도할 것

- `range(끝)`, `range(시작, 끝)`, `range(시작, 끝, 증감폭)`을 직접 여러 값으로 바꿔 출력 결과를 예측해본다.
- `while`을 비밀번호 재입력, 메뉴 반복, 특정 조건까지 숫자 증가 같은 실제 예제로 연습한다.
- `continue`가 있는 코드는 현재 회차에서 어떤 줄이 실행되지 않는지 직접 표시해본다.
- 중첩 반복문은 `i`, `j` 값의 변화를 표처럼 적어가며 추적한다.
- 조건문과 반복문이 섞이면 먼저 바깥 구조를 확인한 뒤 안쪽 코드를 한 줄씩 본다.

## STAR 문제 해결 기록

### Situation — 상황

> 조건문에서는 여러 조건이 동시에 참일 때 어떤 코드가 실행되는지 헷갈렸고, 반복문에서는 `range()`의 숫자 의미와 `while`의 무한 루프 조건, `break`와 `continue`, 중첩 반복문의 실행 흐름이 헷갈렸다.

### Task — 해결 과제

> 조건문과 반복문이 실제로 어떤 순서로 실행되는지 위에서 아래로 추적하고, 각 키워드가 실행 흐름을 어떻게 바꾸는지 구분해야 했다.

### Action — 실행한 행동

1. `if-elif-else`의 조건을 위에서부터 직접 `True`, `False`로 계산했다.
2. `range()`가 실제로 어떤 숫자를 만드는지 직접 펼쳐서 확인했다.
3. `while`문에서 조건 변수의 값이 바뀌는지 한 회차씩 추적했다.
4. `break`와 `continue`가 실행됐을 때 다음에 어떤 코드로 이동하는지 비교했다.
5. 중첩 반복문에서 바깥 반복 한 번마다 안쪽 반복이 처음부터 다시 실행되는 것을 `i`, `j` 값으로 확인했다.

### Result — 결과

- `if-elif-else`에서는 처음 `True`가 나온 블록 하나만 실행된다는 것을 이해했다.
- `range()` 안의 숫자는 변수가 아니라 반복 범위를 정하는 값이라는 것을 이해했다.
- `while True`가 없어도 조건식의 값이 바뀌지 않으면 무한 루프가 발생할 수 있다는 것을 이해했다.
- `break`는 반복문 종료, `continue`는 현재 회차 건너뛰기라는 기본 차이를 이해했다.
- 중첩 반복문은 바깥 반복이 한 번 실행될 때 안쪽 반복이 전체 순회하는 구조라는 것을 이해했다.
- 현재는 반복문의 모든 기본 개념은 이해했으며, `range()` 값 설계, `while` 사용 예시, `continue`, 중첩 반복문은 추가 연습이 필요한 상태다.
