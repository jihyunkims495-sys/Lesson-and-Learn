## 1. What — 무엇을 배웠는가?

### 오늘의 전체 구조

```text
NumPy
→ 숫자 데이터를 배열로 다룬다
→ dtype / reshape / flatten / axis
→ broadcasting / 행렬 연산

Pandas
→ 데이터를 표 형태로 다룬다
→ Series / DataFrame
→ index / column
→ shape / dtypes / info() / describe()
```

오늘 학습한 범위는 데이터 분석 전체 과정 중에서도 **데이터를 어떤 구조로 저장하고 확인할 것인가**에 가까웠다.

### NumPy

NumPy는 **숫자 데이터를 배열 형태로 저장하고 빠르게 계산하기 위한 Python 라이브러리**이다.

```python
import numpy as np

nums = np.array([10, 20, 30], dtype=np.float64)
```

여기서:

```text
np.array(...)
→ NumPy 배열 생성

dtype
→ 배열 원소의 자료형

float64
→ 실수를 64bit 크기의 자료형으로 저장
```

#### bit와 byte

컴퓨터는 데이터를 결국 `0`과 `1`로 저장한다.

```text
1 bit
→ 0 또는 1 하나

8 bit
→ 1 byte
```

따라서:

```text
64 bit ÷ 8
= 8 byte
```

그래서:

```text
int64   → 정수형, 원소 하나당 64bit = 8byte
float64 → 실수형, 원소 하나당 64bit = 8byte
```

중요한 점은 `64`가 숫자의 값이 아니라 **값 하나를 저장하는 자료형의 크기**라는 것이다.

---

### reshape()

`reshape()`는 **원소의 개수와 값은 유지하고 배열의 모양만 변경한다.**

```python
arr = np.array([1, 2, 3, 4, 5, 6])

arr.reshape(2, 3)
```

결과:

```text
[[1, 2, 3],
 [4, 5, 6]]
```

즉:

```text
1차원 배열
→ 2행 3열의 2차원 배열
```

원소는 여전히 6개다.

#### `-1`

```python
arr.reshape(3, -1)
```

의 `-1`은 실제 음수 행이나 열을 의미하지 않는다.

```text
3
→ 행은 3개로 지정

-1
→ 열의 개수는 NumPy가 원소 개수를 보고 자동 계산
```

원소가 6개이므로:

```text
6 ÷ 3 = 2
```

따라서 3행 2열이 된다.

---

### flatten()

`flatten()`은 다차원 배열을 **1차원 배열로 펼친다.**

```python
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

matrix.flatten()
```

결과:

```text
[1, 2, 3, 4, 5, 6]
```

정리:

```text
reshape()
→ 원하는 모양으로 변경

flatten()
→ 1차원으로 펼치기
```

---

### axis

처음 가장 헷갈렸던 개념 중 하나였다.

```python
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

#### axis=0

```python
matrix.sum(axis=0)
```

계산:

```text
1 + 4
2 + 5
3 + 6
```

결과:

```text
[5, 7, 9]
```

즉:

```text
axis=0
→ 같은 컬럼끼리 계산
→ 컬럼별 결과
```

#### axis=1

```python
matrix.sum(axis=1)
```

계산:

```text
1 + 2 + 3
4 + 5 + 6
```

결과:

```text
[6, 15]
```

즉:

```text
axis=1
→ 각 행 안에서 계산
→ 행별 결과
```

좀 더 정확하게는 `axis`가 단순한 x축/y축이라는 뜻은 아니고, **배열의 차원에 붙은 번호**이다.

```text
shape = (2, 3)
         ↑  ↑
      axis0 axis1
```

현재 단계에서는 다음처럼 기억하는 것이 가장 이해하기 쉽다.

```text
axis=0 → 컬럼별 결과
axis=1 → 행별 결과
```

---

### Broadcasting

Broadcasting은 **크기가 다른 배열을 NumPy가 연산 가능한 형태로 자동 확장하여 계산하는 기능**이다.

```python
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

row = np.array([10, 20, 30])
```

```python
matrix + row
```

계산되는 모습:

```text
[1, 2, 3] + [10, 20, 30]
[4, 5, 6] + [10, 20, 30]
```

결과:

```text
[[11, 22, 33],
 [14, 25, 36]]
```

즉 작은 배열을 실제로 복제해서 저장하는 것이 아니라 **확장된 것처럼 계산한다.**

---

### 행렬곱

NumPy의 행렬곱은 `@`를 사용한다.

```python
A @ B
```

오늘은 복잡한 수학 공식보다 다음 개념까지만 이해했다.

```text
* → 같은 위치의 원소끼리 곱함

@ → 앞 행렬의 행과
     뒤 행렬의 열을 이용한 행렬곱
```

## Pandas

Pandas는 **행과 열이 있는 표 형태의 데이터를 다루기 위한 Python 라이브러리**이다.

NumPy가 숫자 배열 자체의 계산에 집중한다면 Pandas는 데이터에 행과 열의 의미를 붙여 사람이 이해하기 쉬운 형태로 관리할 수 있다.

```python
import pandas as pd

df = pd.DataFrame({
    '중간고사': [80, 95, 70],
    '기말고사': [85, 90, 75]
}, index=['김철수', '이영희', '박민수'])
```

표:

```text
        중간고사  기말고사
김철수      80      85
이영희      95      90
박민수      70      75
```

---

### DataFrame과 Series

#### DataFrame

```text
DataFrame
→ 행과 열로 구성된 2차원 표
```

위 예시는:

```text
3행 2열
```

이다.

#### Series

DataFrame에서 컬럼 하나를 꺼내면 기본적으로 `Series`가 된다.

```python
df['기말고사']
```

결과:

```text
김철수    85
이영희    90
박민수    75
```

이 구조는 1차원 `Series`이다.

```text
Series
→ 1차원

DataFrame
→ 2차원
```

---

### index와 column

```text
column
→ 열의 이름

index
→ 각 행에 붙어 있는 이름표
```

예:

```text
중간고사, 기말고사
→ column

김철수, 이영희, 박민수
→ index
```

처음에는 Series 출력에서 이름과 숫자가 함께 보이기 때문에 두 개의 컬럼처럼 느껴졌다.

하지만:

```text
김철수    85
```

에서 `김철수`는 데이터 컬럼이 아니라 `85`라는 값에 붙어 있는 **index**이다.

### shape

`shape`는 **데이터가 어떤 모양으로 구성되어 있는지 보여주는 속성**이다.

DataFrame:

```python
df.shape
```

결과:

```text
(3, 2)
```

뜻:

```text
3행 2열
```

즉:

```text
DataFrame의 shape
= (행 개수, 열 개수)
```

Series는:

```python
df['기말고사'].shape
```

결과:

```text
(3,)
```

값이 3개인 1차원 구조라는 의미다.

비교:

```text
Series
shape = (3,)
→ 1차원

DataFrame
shape = (3, 1)
→ 3행 1열의 2차원
```

## 2. Why — 왜 필요한가?

### NumPy

Python의 기본 리스트로도 숫자를 저장할 수 있지만, 머신러닝이나 데이터 분석에서는 매우 많은 숫자를 반복해서 계산해야 한다.

NumPy는 숫자 데이터를 일정한 자료형의 배열로 관리하고 빠르게 연산할 수 있게 해준다.

```text
NumPy
→ 숫자를 계산하기 좋은 형태로 다루는 도구
```

### Pandas

실제 데이터는 단순히 숫자만 나열되어 있는 것이 아니라:

```text
이름
상품
가격
점수
날짜
지역
```

처럼 각 값이 무엇을 의미하는지가 중요하다.

Pandas는 NumPy의 숫자 배열보다 사람이 이해하기 쉬운 **행과 열이 있는 표 형태**로 데이터를 다룰 수 있게 해준다.

```text
Pandas
→ 데이터를 구조화하고 확인·분석하기 위한 도구
```

둘을 연결하면:

```text
Pandas
→ 데이터를 표 형태로 읽고 정리

NumPy
→ 숫자 배열을 계산

Machine Learning
→ 정리된 숫자 데이터를 이용해 학습
```

앞으로 머신러닝에서 계속 사용할 데이터 처리의 기초라고 이해했다.

## 3. How — 어떻게 이해했는가?

### NumPy 실행 흐름

```text
데이터 준비
↓
np.array()
↓
NumPy 배열 생성
↓
dtype으로 데이터 타입 확인/지정
↓
shape으로 배열 모양 확인
↓
reshape()로 모양 변경
↓
axis를 지정해 원하는 단위로 계산
↓
필요하면 broadcasting으로 여러 값에 연산
```

### Pandas 실행 흐름

```text
데이터 준비
↓
pd.DataFrame()
↓
행과 열이 있는 표 생성
↓
column과 index로 데이터 의미 구분
↓
shape으로 표의 크기 확인
↓
dtypes로 컬럼의 자료형 확인
↓
info()로 전체 구조 확인
↓
describe()로 숫자 데이터 통계 확인
```

### 내 말로 설명하기

> NumPy는 숫자를 배열에 넣고 계산하기 위한 라이브러리이고, Pandas는 데이터를 행과 열이 있는 표로 만들어 관리하고 분석하기 위한 라이브러리라고 이해했다. NumPy에서는 배열의 모양과 연산 방향이 중요하고, Pandas에서는 데이터가 몇 행 몇 열인지, 각 컬럼에 어떤 자료형이 들어 있는지를 파악하는 것이 먼저다.

## 4. 오늘의 문제 해결

### 문제 상황 1 — `int64`, bit, byte가 왜 나오는지 이해되지 않았다

처음에는:

```text
int64 = 64bit = 8byte
```

라는 설명에서 왜 갑자기 저장공간 이야기가 등장하는지 이해되지 않았다.

#### 해결

컴퓨터에서 값을 변수에 저장하려면 그 값을 메모리에 기억해야 한다.

```text
1 byte = 8 bit
```

이므로:

```text
64 bit = 8 byte
```

이고 `int64`, `float64`의 `64`는 데이터 값이 아니라 **숫자 하나를 저장하는 자료형의 크기**라는 것을 이해했다.

---

### 문제 상황 2 — NumPy 2차원 슬라이싱

처음 다음 코드를 작성했다.

```python
print(matrix[0:2], [1:3])
```

`[1:3]` 자체에는 슬라이싱할 대상이 없기 때문에 문법 오류가 발생했다.

2차원 NumPy 배열에서는:

```python
matrix[행범위, 열범위]
```

형태를 사용한다.

```python
matrix[0:2, 1:3]
```

즉 한 대괄호 안에서 쉼표를 기준으로 행과 열을 구분한다.

---

### 문제 상황 3 — axis=0과 axis=1

강의 중 `axis=0`과 `axis=1`을 행/열로 설명하면서 기준이 계속 반대로 느껴졌다.

직접 계산해보면서:

```text
axis=0
→ 같은 컬럼의 값을 계산
→ 컬럼별 결과

axis=1
→ 같은 행 내부의 값을 계산
→ 행별 결과
```

라는 결과 기준으로 이해했다.

또 `axis`는 그래프의 x축/y축이라기보다 **배열의 차원 번호**라는 점을 알게 되었다.

---

### 문제 상황 4 — Series가 왜 1차원인지 이해되지 않았다

```text
김철수    85
이영희    90
박민수    75
```

를 보고 이름과 숫자 두 컬럼이 있으므로 2차원처럼 느껴졌다.

하지만 `김철수`, `이영희`, `박민수`는 데이터 컬럼이 아니라 **index**였다.

```python
df['기말고사'].shape
```

```text
(3,)
```

이므로 값 3개가 있는 1차원 Series이다.

반면:

```python
df[['기말고사']].shape
```

은:

```text
(3, 1)
```

이어서 3행 1열의 2차원 DataFrame이다.

### 현재 이해도

**★★★★☆**

NumPy와 Pandas가 각각 왜 필요한지는 이해했다. `reshape`, `flatten`, 기본 `axis` 연산과 Pandas의 기본 데이터 구조도 설명할 수 있다.

다만 `axis`를 추상적인 차원 개념으로 설명하는 것과 행렬곱은 아직 반복 확인이 필요하다. Pandas의 Series와 DataFrame 차이는 `shape`을 통해 이해하면서 정리가 되었다.
