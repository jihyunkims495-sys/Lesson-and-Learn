## 읽는 기준

- 초기 가설의 도착지는 같은 서비스의 앱 Cart였다. 구현·비교 범위는 이후 휴대폰 브라우저의 모바일 웹으로 구체화했으므로, 채널 범위는 B·C PC 웹→모바일 웹 가설을 따른다.
- 현재 합의한 결제 측정 종료점은 `payment_button_click`이다. Toss API는 연결하지 않으며, 버튼 클릭은 결제 승인·구매·매출이 아니다.
- 문서에 남아 있는 `purchase`·Toss 승인 항목은 후속 설계다. 현재 구현·실험 완료로 해석하지 않는다.
- 계정 생성 수, 유효 행동 실행 수, GA 사용자 수와 이벤트 수는 서로 다른 집계다. 소수 파일럿 결과를 180명 본 실행 결과로 합산하지 않는다.
- 가상 회원의 행동은 배정한 조건의 시뮬레이션이다. 실제 20~30대 고객 선호나 통계적 우위를 입증하지 않는다.
