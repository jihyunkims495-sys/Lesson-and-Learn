# SAN SAN GEAR local recreation

산산기어 공개 사이트의 화면 구조와 공개 자산을 바탕으로 만든 Next.js 로컬 프런트엔드입니다. 공개 사이트의 기본 스타일, Adobe Fonts 키트, 영상·이미지를 사용합니다. 온라인 자산과 웹폰트는 인터넷 연결이 필요합니다.

- 홈의 90개 콘텐츠 블록, 영상, 포인터·스크롤 반응선, 푸터
- 데스크톱 호버 메뉴, 모바일 단계별 메뉴, SAN SAN GEAR / TOJI 전환
- 상품 366개, 공개 컬렉션 42개, 시즌·소분류별 목록, 36개씩 추가 로딩
- TOP 진입 시 ALL / T-SHIRTS / HOODIES / LONG SLEEVES / KNITWEAR / SHIRTS 표시
- 데스크톱 3/4/6열과 모바일 1/2/3열, 원본 이미지 프레임·여백
- 상품별 연속 이미지, 사이즈 선택, 실측표, 관리 안내, 스타일링 이미지, 추천·최근 본 상품
- 아카이브 43개와 개별 이미지 페이지, 시즌 전환
- 매장·스톡키스트·도움말·법적 안내, TOJI 홈·매장·컬렉션
- 검색, 로컬 장바구니와 수량 변경, 한국어/영어 경로

`data/reference.json`에는 상품·컬렉션·홈·페이지 정보가, `data/details.json`에는 공개 상품 상세와 아카이브 정보가 들어 있습니다. 화면 자료를 다시 확인한 날짜는 2026-10-20입니다. 가격과 재고는 저장 시점의 값입니다.

장바구니는 브라우저 localStorage에 저장합니다. 로그인·결제·상담은 실제 서비스 서버에 연결하지 않은 로컬 화면입니다. 외부에 배포하거나 실제 주문을 전송하지 않습니다.

정적 빌드: `npm run build`. 정적 HTML은 `out/`에 생성됩니다. 공개 컬렉션 문맥의 상품 URL과 `/en` 경로도 생성합니다.
