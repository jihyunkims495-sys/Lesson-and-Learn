# Project 2 · AsyncTicket

FastAPI와 PostgreSQL로 구현한 공연 티켓 예매 팀 프로젝트입니다.

- 회원가입·JWT 인증, 공연장·공연·회차·좌석 관리
- 좌석 예매·만료 처리와 결제·취소 API
- Jinja2 기반 조회·관리 화면과 공연·회차 조회 캐시

Python 3.13, SQLAlchemy, asyncpg, Jinja2를 사용합니다.
